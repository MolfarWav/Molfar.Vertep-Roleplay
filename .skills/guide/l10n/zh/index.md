# 角色扮演：总览

角色扮演是 Molfar Vertep 的故事应用：你保存角色卡，与他们进行聊天扮演，并让应用追踪场景、记住故事、运行你周围的世界。本页是一张地图。应用自带的 **Help**（在侧边栏中）几乎为每个界面都有一篇短文；本指南解释各部分如何组合在一起。模型和连接不在这里设置，而是在主设置中：参见 [[vertep:models]]。

## 各部分在哪里

左侧的侧边栏（在手机上是一排底部标签）对各个部分进行了分组：

- **Home** 和 **Chats**：从你停下的地方继续，或打开任意聊天。
- **Characters**、**Groups**、**Marketplace**、**Personas**：人物。参见 [[characters]]。
- **Lorebooks**、**Library**、**Canvas**、**World**、**DM**、**Agents**：故事的记忆和机制。DM 会打开 World 部分的 DM 标签页（DM 的等级、配置文件和 Memory）。参见 [[memory]]、[[litopys]]、[[canvas]]、[[world-dm]] 和 [[agents]]。
- **Presets**：发给模型的请求是如何构建的。
- **Shortcuts** 和 **Tools**：快捷回复、正则、翻译、图片、语音、Data Bank 等。参见 [[settings]]。
- **Inbox** 和 **Help** 在底部。Inbox 列出等待你处理的事项：失败的后台任务、Library 建议和提议的灵魂。

角色扮演自己的设置没有侧边栏条目。用 Home 标题栏中的 "Roleplay settings" 按钮打开它们（在手机上，在菜单中）。

## 在聊天内部

聊天标题栏中放着故事工具：**Note**（作者注）、**Fired**（进入了提示词的内容，参见 [[memory]]）、**Record** 和 **World**。菜单旁边的 **Backstage** 按钮会在聊天上方打开构成这个故事的地方：这个角色的卡片、预设、它的 lorebook、Library 和此聊天的 World，以及进入了什么。关闭抽屉后，你仍在同一条消息上。制作者一侧的抽屉（Lorebooks、Library、World、Presets 以及那一层的其他部分，还有 Dashboard settings）带有一个小小的 **Backstage** 标签和略微不同的页面色调，这样你一眼就能看出自己身处幕后。旁边的胶囊按钮打开此聊天的 Preset、Persona、Model 和 Agents 标签。在 Preset 标签中，**Saved setups** 以名称保存你对某个预设的选择：轻点即可加载，把聊天的选择以新名称保存，并给使用该预设的新聊天默认采用的那一个加星标。每条消息上的 "More" 按钮打开其操作，消息框旁边的 "+" 菜单包含 Polish、Regenerate with a hint、Stage direction、图像生成等。

有三个助手会观察故事并消耗额外的模型调用，所以值得了解它们：

- **Dashboard** 阅读每个场景：[[dashboard]]，有一个输入，即角色的 [[soul]]。
- **Litopys** 撰写章节和事实：[[litopys]]。
- **World DM** 保存一本人物和地点之书：[[world-dm]]。

## 本指南中的页面

- [[first-story]]：从零到你的第一条回复，以及在小型或慢速模型上应关闭什么。
- [[characters]]：卡片、卡片编辑器、角色、群组、导入。
- [[sprites]]：聊天上方的立绘、群组或叙述者的多个窗口、视觉小说风格。
- [[soul]]、[[dashboard]]、[[litopys]]、[[world-dm]]、[[agents]]：故事机制。
- [[direction]]：在群聊中，一个小型导演模型读取场景中的角色；进度条、锁定、新群组。
- [[meanwhile]]：屏幕外的人物在场景之间行动（测试版本，默认关闭）。
- [[places-map]]：聊天中地点的浮动地图，带有道路和你自己的图片。
- [[places-map-levels]]：一个聊天中的多张地图（一个国家、一座城市、一个地牢），以及用图像模型绘制地图。
- [[memory]]：哪种记忆用于什么。
- [[canvas]]：聊天链接、提示词板和智能体锻造台。
- [[long-chats]]：为什么长聊天会变慢或变贵，什么会削减它，以及如何把故事带入新聊天。
- [[settings]]：每个设置在哪里。
