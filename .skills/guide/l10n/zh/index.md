# Roleplay：概览

Roleplay是Molfar Vertep的故事应用：你保存角色卡，与它们进行聊天，并让应用跟踪场景、记住故事并运行你周围的世界。本页是一张地图。应用自带的**Help**（在侧边栏中）几乎为每个页面都提供了简短文章；本指南解释各个部分如何协同工作。模型和连接不在这里设置，而在主Settings中设置：参见[[vertep:models]]。

## 各部分的位置

左侧的侧边栏（在手机上为底部标签栏）将各部分分组：

- **Home**和**Chats**：从上次停下的地方继续，或打开任意聊天。
- **Characters**、**Groups**、**Marketplace**、**Personas**：人物。参见[[characters]]。
- **Lorebooks**、**Library**、**Canvas**、**World**、**Agents**：故事的记忆和机制。参见[[memory]]、[[litopys]]、[[world-dm]]和[[agents]]。
- **Presets**：如何构建发送给模型的请求。
- **Shortcuts**和**Tools**：快速回复、正则表达式、翻译、图片、语音、Data Bank等。参见[[settings]]。
- **Inbox**和**Help**位于底部。Inbox列出等待你处理的事项：失败的后台任务、Library建议和提议的soul。

Roleplay自身的设置没有侧边栏项。通过Home顶部的“Roleplay settings”按钮打开（在手机上则在菜单中）。

## 聊天内部

聊天顶部包含故事工具：**Note**（作者备注）、**Lore**、**Record**和**World**。旁边的胶囊菜单打开此聊天的Preset、Persona、Model和Agents标签页。每条消息上的“More”按钮打开其操作，消息框旁边的“+”菜单包含Polish、Regenerate with a hint、图像生成等功能。

三个助手会观察故事并消耗额外的模型调用，因此值得了解它们：

- **Dashboard**读取每个场景：[[dashboard]]，其输入之一是角色的[[soul]]。
- **Litopys**撰写章节和事实：[[litopys]]。
- **World DM**维护人物和地点的设定集：[[world-dm]]。
