# Roleplay：概述

Roleplay 是 Molfar Vertep 的故事应用：你保存角色卡、与他们进行聊天游玩，并让应用追踪场景、记住故事、运转你周围的世界。本页是一张地图。应用自带的 **Help**（在侧边栏中）几乎每个界面都有一篇短文；本指南解释各部分如何组合在一起。模型和连接不在这里设置，而是在主 Settings 中设置：参见 [[vertep:models]]。

## 各功能的位置

左侧的侧边栏（在手机上为底部的标签栏）将各个部分分组：

- **Home** 和 **Chats**：从你停下的地方继续，或打开任意聊天。
- **Characters**、**Groups**、**Marketplace**、**Personas**：人物。参见 [[characters]]。
- **Lorebooks**、**Library**、**Canvas**、**World**、**Agents**：故事的记忆与机制。参见 [[memory]]、[[litopys]]、[[canvas]]、[[world-dm]] 和 [[agents]]。
- **Presets**：发给模型的请求是如何构建的。
- **Shortcuts** 和 **Tools**：快捷回复、正则、翻译、图片、语音、Data Bank 等。参见 [[settings]]。
- **Inbox** 和 **Help** 在底部。Inbox 列出等待你处理的事项：失败的后台任务、Library 建议和提议的 soul。

Roleplay 自己的设置没有侧边栏条目。用 Home 标题栏中的 "Roleplay settings" 按钮打开它们（在手机上，在菜单中）。

## 聊天内部

聊天标题栏包含故事工具：**Note**（作者注）、**Fired**（进入了提示词的内容，参见 [[memory]]）、**Record** 和 **World**。旁边的胶囊按钮打开此聊天的 Preset、Persona、Model 和 Agents 标签页。每条消息上的 "More" 按钮打开其操作，消息框旁的 "+" 菜单包含 Polish、Regenerate with a hint、Stage direction、图片生成等。

有三个助手会观察故事并消耗额外的模型调用，因此值得了解它们：

- **Dashboard** 读取每个场景：[[dashboard]]，有一个输入，即角色的 [[soul]]。
- **Litopys** 撰写章节和事实：[[litopys]]。
- **World DM** 维护一本人物和地点的书：[[world-dm]]。

- [[first-story]]：从零到你的第一条回复，以及在小型或慢速模型上应关闭什么。
- [[characters]]：卡片、卡片编辑器、personas、groups、导入。
- [[sprites]]：聊天上方的立绘、为群组或旁白开设的多个窗口、视觉小说外观。
- [[soul]]、[[dashboard]]、[[litopys]]、[[world-dm]]、[[agents]]：故事机制。
- [[places-map]]：聊天地点的浮动地图，带有道路和你自己的图片。
- [[memory]]：哪种记忆用于什么。
- [[canvas]]：聊天链接、提示词板和 agent forge。
- [[long-chats]]：为什么长聊天会变慢或变贵、什么能削减它，以及如何将故事带入新聊天。
- [[settings]]：每项设置在哪里。
