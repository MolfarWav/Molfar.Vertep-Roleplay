# Canvas：聊天链接、提示与智能体

Canvas是Roleplay的技术工作台：一个由多个面板组成的界面，你可以在这里查看并修改聊天之间的连接，以及每个聊天向模型发送的内容。玩故事不需要它。当故事需要续篇、回复出乎意料，或你要构建智能体时，再打开它。

用顶部的**Board**开关选择面板：**Chat links**、**Prompt**、**Agents**和**Agent sets**。侧边栏中的Agents条目会打开同一个Canvas，并定位到其Agents面板。你上次使用的面板会被记住。

## Chat links

这是你的聊天地图。每个聊天是一张卡片。从一个聊天指向另一个聊天的连线表示“本聊天承接那个聊天”：较早聊天的故事会作为背景故事，随之带入较晚聊天的回复，并受Library中设置的背景故事预算限制。最近的三个较早聊天会被完整读取，更早的则会被浓缩（[[long-chats]]）。实线表示承接关系。虚线表示从某条消息分叉出来的分支。

- 尚未放到面板上的聊天会在左侧的列表（**Chats**）中等待。将它拖到面板上，或使用**Put on the board**（配合**its linked chats**可以把整条链一起放上来）。把卡片拖回列表，或使用**Remove**，即可将其从面板上移除。聊天本身仍保留在Library中。
- 打开**Edit**开关，即可连接或断开卡片。会形成循环的链接、把聊天连接到自身，或重复已有的链接都会被拒绝，面板会说明原因。提供**Undo**和**Redo**。**Fit**会把整个图形框入视野。
- 在手机上，面板以**View**模式打开，并提供链接的**List**。在大屏幕上构建图形更方便，但你仍然可以在列表中编辑链接。

Library中对某个聊天的地图显示的是同一条链，但只能查看。它的**Edit on canvas**按钮会带你来到这里。

## Prompt

选择一个聊天，即可查看它发送给模型的请求。面板有两个视图：**Parts**和**Memory**。

- **Parts**列出请求的每一部分：主提示、角色卡、人格、Lorebook条目、示例对话、预设的各个段落以及历史记录，每项都带有其token数和状态。某一部分可能处于以下状态：在预设中关闭、在本聊天中关闭、为空，或不适用于此类回复。你可以只为这一个聊天关闭某部分，而不改动预设。**Only what is sent**会隐藏其余部分，总计则显示模型实际收到的内容。
- **Memory**解释记忆为上一条回复放入了什么。完整说明见[[memory]]。

如果只想快速查看上一条回复中触发了什么，可使用聊天顶部的**Fired**按钮。Memory视图和**Fired**读取的是同一份记录；Fired还会统计整个聊天的情况。

## Agents和Agent sets

智能体工坊：构建智能体、试运行，并将智能体分组为智能体集。参见[[agents]]。

## 保持不变的内容

在Prompt面板上关闭某一部分，只对该聊天生效。预设和角色卡都不会改变。
