# World DM

World DM 是一个聊天的世界的游戏主持人。在回复之后，它阅读故事，并将遇到的人物、地点和物品保存在聊天自己的传说书（称为世界书）中。在更高的级别，它还会推动世界发展，并向场景中发送事件。当你希望世界感觉生动且连贯时使用它。

## 级别

从聊天标题栏的 "World"（在手机上，菜单，然后 World）打开，或从侧栏的 **World** 部分打开。选择 DM 做什么：

- **Off**：没有事件，没有骰子。世界书仍然从故事中填充：当场景提到一个新地点或物品时，一次小型调用询问 DM 模型是否记录它。
- **Chronicler**：仅记录，不添加自己的事件。
- **Living world**：派系和威胁在幕后移动。消息可能作为传闻到达角色；没有强制的事情。
- **Director**：将钩子、复杂情况和访客带入场景，下一个回复必须使用它们。
- **Antagonist**：针对角色所关心之物的后果和压力。
- **Total chaos**：任何事情都可能发生，无论什么类型。它从不重写故事，并等待明确的场景结束。

默认情况下，在故事聊天中，DM 已从第一条回复起以 Chronicler 级别开启（对于所有卡片都是助手的聊天则不开启）。如果你不想要它，在 World 面板的 Overview 中关闭它。

## 每轮它做什么

它在回复之后运行，每第 N 条回复运行一次（"Run after every N replies"），或立即通过 "World turn" 运行。它阅读新消息并在世界书中写入或退役记录：人物、地点、物品以及谁持有它们。你可以在 World book 标签中给一个 Group 或 Place 记录添加 **Members**（属于该群体的人）；在 Litopys 中告诉该群体的事实随后每个成员都知道（[[litopys]]）。DM 不会自己填充 Members。从 Living world 级别起，它还会推动战线和时钟，并可能准备一个事件添加到下一个回复中。使用 **Code** 推动时钟（World > Profiles > Options）时，每 N 条回复代码为每个战线掷一个 d6：1-2 无事，3-4 推进一步，5-6 推进一步并告知 DM 该战线的消息可能到达故事中。可选骰子（World 面板，Dice，从 Living world 级别起，默认关闭）：在回复之前，代码掷 2d6 并告诉模型一个不确定的行动结果如何，作为 Hint 或 Binding。**Pacing check, %** 选项（Dice 详情，默认关闭）为用户角色向亲密迈出一步的时刻添加第二次隐藏掷骰：它落得如何取决于角色的舒适度、信任和来自 Dashboard 的好感度，模型将其演绎为未准备好、犹豫、紧张地接受或欢迎。它从不阻止回复，也从不提及骰子。

每当到期时，它会消耗一次额外的模型调用，使用 "DM model (all chats)"；一个小而便宜的模型就足够了。失败的运行会显示在面板和 Inbox 中，DM 下次会再次阅读相同的消息。

DM 会看到每个记录的名称，但只有新消息触及的记录才会完整显示：它们提到的记录、场景的地点及其所在之物、场景中的人物、固定的记录以及即将回归的人物。这样可以让包含许多记录的书保持低成本。DM 仍然可以更改或退役任何记录。

从事件牌堆播放的配置文件在牌堆用尽时显示 "New deck"。模型被要求提供 8 到 12 个事件；如果返回的更少，牌堆保持原样，并有一条警告说它返回不足，以便你可以重新构建它。

## 人物回归

来自卡片传说书的朋友或亲戚可能在故事中消失一百条消息，因为条目只有在有人说出名字时才会出现。DM 会带回这样的人。它计算自某人上次出现在场景中以来的回复数（开启 Dashboard 时，仅文本中的名字只是提及，不会重置计数；发短信或打电话的远方朋友算作在场景中），当沉默时间很长时（大约 15、30 或 60 条回复，由 **People coming back > How often** 决定；Normal 是新聊天的默认值），它坚定地告诉写作模型，此人进入此回复。一次隐藏的 2d6 掷骰，加上沉默的长度和此人的分量，决定回归的规模：一条消息、一个带有请求的电话，或某人带着消息到来。模型选择形式；DM 检查此人是否出现，如果没有则再问一次。如果写作者只是提到此人，日志会显示 "only mentioned, not on stage"，不会进行第二次尝试；在这样的中等或大型回归之后，下一次回归在通常停顿的一半时间后进行，且至少为中等规模。卡片的传说书中的人物通过 **Take people from the cards' lorebooks** 或 Start 开关 "People from the lorebooks" 加入替补席。在人物或派系记录上，你可以设置 Relation、Weight 和 "Bring back automatically"。要看到它工作，开启 **Show under the reply**：一个小标记说明谁来了、为什么以及骰子如何落下；卡片还会列出替补席中每个人的沉默时间和回归日志。

## 来自演员牌堆的新人物

替补席带回故事中已有的人物。**cast deck** 引入尚未遇见的人物。牌堆是一叠卡片：一个名字、一个派系（世界中的一个群体或战线）、一个已存在的与此新人有关联的人（表亲、债务人、对手）、他们想要什么，以及关于他们的五到十句话。DM 从不看到卡片；当替补席上没有人到期且故事已经安静了大约与回归相同的时间时，DM 选择一张卡片，优先选择其关联在场景中的，然后是其派系战线被搅动的，然后是其派系属于此地的，并坚定地告诉写作模型，这个新人通过那个关联进入回复。当他们出现时，卡片变成书中的一个人物，其派系的成员。如果他们没出现，卡片等待。

Start 可以编写牌堆（开关 **New people for later**，包含派系数量、每个派系的人数以及卡片长度），当剩余卡片少于 3 张时牌堆会自动填充。在聊天的 World 面板中，**Cast deck** 卡片有开关、剩余卡片数、**Add new people now** 以及每次抽取和补充的日志。书有一个 **Cast deck** 标签：卡片在 **Show the cards** 后面，因为它们会剧透即将到来的内容；你可以编辑或删除卡片，没有关联的卡片会被标记。

## 世界书及其整理

聊天的 World 面板有 DM 保存内容的磁贴：**People**、**Places**、**Factions** 和 **Things**，然后是 **Archive** 以及 **Fronts** 和 **Runs**。按一个磁贴以在该类型处打开世界书（由 Start 在故事之前构建的世界仍然会问一次剧透问题；已玩过的聊天会立即打开）。书是一个列表，可搜索名称、键和文本，每种类型有颜色标签，卡片可折叠其文本；Edit、Retire、Pin 和 Delete 照旧工作。一个物品可以有一个 **reason**（线索、隐藏之物、承诺、礼物、武器、人们争夺的东西）；DM 在记录时说明它，你可以在表单中更改它。

事实不再是记录。一个习俗、法律或一段历史属于它所描述的地点或派系的文本中，而人们知道或隐藏的东西属于 Litopys。仍有旧笔记的书会显示一个横幅和一个 **Old notes** 磁贴；在每个笔记上选择 **Fold into…** 一个地点或派系（其文本增加该笔记）或 **To the Litopys**（一个所有人都知道的事实，最多 300 个字符）。

书也会自我整理。每 10 条回复，一个物品如果在最近 10 条回复中被少于 3 条提及、不属于任何人（不被你的角色、卡片角色或书中的人物持有，也不在 Dashboard 中角色的手中）、未被固定且不是线索、隐藏之物或承诺，就会进入 **Archive**，从故事模型的视野中消失。当故事两次提到它，或 DM 再次提到它时，它会回来；你也可以按 **Wake**。**Tidying the book** 卡片有开关、**Tidy now**（立即执行一次；聊天的第一次执行只取物品列表）以及每次归档和每次唤醒的日志，附带决定它的计数。人物、地点和派系从不被整理掉。你删除的记录不会被 DM 再次写入，DM 会被告知你移除了哪些名字。

## 删除或滑动回复

删除一条回复，或滑动到另一条，DM 会收回它从旧回复中学到的东西：记录、时钟和等待中的事件恢复到原来的样子，世界书被重新写入，DM 从那里重新阅读故事。你手动更改的记录会保留，除非 DM 之后更改了同一记录。你删除的记录保持删除。从顶部删除旧消息、阅读旧回复的其他滑动以及编辑回复的文本不会收回任何东西。

一个事件是一次性的。DM 检查故事是否展示了它，查看携带它的回复之后的所有内容，也包括它已经读过的部分。如果没有，事件会随下一个回复再次发送，除非故事到那时已转移到另一个地方（时间跳跃、新场景）：那么它被放弃，以免旧事件把故事拉回去。

滑走携带 DM 事件的回复会随新回复再次发送该事件。也滑走那一条，事件就被丢弃：DM 认为你不想要它，Memory 从中学习（见下文）。删除或失败的回复不计入。

## 当某人永久离开

当一个人死亡、永久离开故事，或一个地点或群体被摧毁时，DM **退役**该记录；你可以自己用记录上的 **Retire** 来做（或用 **Delete** 删除它，DM 不会再写入它）。退役的记录作为一条简短笔记留在世界书中，说明它已从故事中消失，这样故事记住它如何结束，并且永远不会自己回来。退役也会带走挂在其上的东西：事件牌堆中命名它的卡片、与该人物关联（或属于被摧毁群体）的演员牌堆卡片，以及该人在群体 **Members** 中的位置。如果此人来自卡片的传说书，该卡片条目在此聊天中被静音，这样其关于活人的文本不会盖过笔记。书中该记录的卡片列出了所有这些。**Bring back** 将此人放回那些群体并取消卡片条目的静音；被丢弃的卡片保持丢弃。一个仍活着的被击败的敌人不会被退役：如果你不想让他们回来，在记录上关闭 "bring back automatically"。

## World 部分标签

World 列表标题旁的齿轮打开 **World settings**，以类似 Litopys 设置的可折叠块呈现：游玩模型（有一个为此 World 覆盖它的开关、回复限制和一个测试按钮）、构建模型、图像模型、背景开关以及是否告知你失败。折叠的块用一行显示设置内容。

在选定的聊天上：Overview（与面板相同的控件）、Places（地点的树，每个地点有背景图片；相同的地点也是聊天上方的浮动地图，见 [[places-map]]）、World book（手动读取、写入、退役或删除记录）、Runs（历史、令牌、错误）、Start（从卡片或简短访谈起草记录）、Backgrounds（规划和绘制一组图片；开启 "Change the background by scene" 时，Dashboard 选择合适的一张；同时开启 "Draw places that have no picture" 时（它总是列在那里，在场景开关和图像生成开启之前呈灰色），故事转移到一个没有图片的地点时，会由 World 的图像模型当场绘制，归档到文件夹并在 Places 中设置为该地点的图片（当世界有它的记录时）；同一地点后来措辞不同（"The Hall" 的 "the hall at night"）会重用图片而不是再次绘制；那里的 "Look of the pictures" 接受几个英文单词（例如 `medieval fantasy, candlelight`），它们会被添加到为该聊天绘制的每个背景、当场绘制的地点或一组图片中；聊天的 Display 面板有一个指向这里的链接）。还有 **Profiles** 和 **Worlds**。

## World 配置文件

每个级别都是一个内置配置文件：这五个配置文件持有 DM 的提示词，你可以打开一个、更改一个提示块并将其回滚到默认值。你也可以在一个级别之上创建自己的配置文件。聊天在 DM 面板中选择其配置文件。新聊天以 Chronicler 开始，除非你在另一个配置文件上按 **Make default**（**DM** 标签，在配置文件的标题中）：它获得一个 *Default* 标签，每个新聊天以其级别、数字和提示词开始；你已有的聊天保持自己的设置，DM 的 "off" 是按聊天选择的，不能作为默认值。"Saved worlds" 保存你构建并在其中开始新聊天的世界；"New world" 在任何聊天之前从卡片或简短访谈构建一个世界。

## DM 学到什么

**DM** 标签（Chats | Worlds | DM）以 **Memory** 行开始；标签上和行上的点表示有一个提案等待你。DM 注意到你在世界书中删除和重写的内容，并且从不自行更改：当模式清晰时，**Memory** 显示一个提案及证据（你移除了什么、这是 DM 自己记录的多少、阈值）和三个答案：**This chat**、**All chats** 或 **No**。为此不调用任何模型。一个答案更改一个确切的设置：新的 **Things in the book** 设置（全部、仅有理由的、或无）、记录文本的长度，或人物回归的频率。"No" 在新编辑积累之前不会再被询问。

人物、地点和群体没有可翻转的设置。当你删除许多 DM 写的这类记录时，Memory 显示一个 **rule in words**：打开 Memory 会对构建模型进行一次小型调用，根据你移除的和保留的内容写出规则（一行），或找不到模式。**Suggest a rule from my edits** 手动请求一个。你以相同方式回答；适用于所有聊天的规则会在一个显示它的对话框中再问一次。DM 将你的规则作为一个短块阅读，*what this player prefers*（此聊天的和所有聊天的合在一起，最新的在前，最多 10 条规则和 600 个字符；不适合的较旧规则留在 Memory 中并带有标签），**Add a rule** 也接受文字规则。

事件也计入。当你滑走了三个或更多 DM 的事件（每个两次，因此被丢弃），且这是它发送的事件中的三分之一或更多时，Memory 提出一个 **about the story** 的规则（例如 "Do not interrupt quiet scenes with sudden attacks"）。故事规则有自己的标签；DM 在选择事件时遵守它，而当 **Tell the reply model too** 开启时（**What the DM learns** 卡片），最新的三条故事规则也作为一行短句进入编写回复的请求中。当你手动添加文字规则时，**About** 选择书（DM 记录的内容）或故事。

Memory 还显示 **Kept on purpose**：你固定、编写或手动带回的记录。DM 将它们的名字视为你希望在书中看到的示例，编写规则的调用也会看到它们。

在 Memory 中，你还可以阅读生效的规则（标签说明规则是用于此聊天还是所有聊天）、更改或移除一条、手动添加规则、查看 **Remembered exactly**（你删除的名字，DM 被告知不要再写入）并清除它们，或 **Reset all**。适用于所有聊天的规则在每次打开聊天时到达每个聊天，以及新聊天；之后在聊天中手动设置的值会保留。规则不随保存的世界一起旅行。配置文件编辑器以一个只读卡片 **Learned memory** 结束，显示添加到 DM 输入中的内容。在聊天的 World DM 面板中，**What the DM learns** 卡片有一个开关（"Propose from my edits"）、开关 **Tell the reply model too**、物品设置、生效的学习规则数量以及每个提案和答案的日志。
