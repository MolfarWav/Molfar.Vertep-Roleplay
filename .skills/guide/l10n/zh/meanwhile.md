# 幕后：屏幕之外的生活

幕后让不在场景中的人物在故事进行时做事情：Bram 在港口卖掉一匹马，Ada 藏起账本，一条战线离它的目标又近了一步。这是一个测试版本，默认关闭。

## 开启它

打开聊天的 **World** 面板，找到 **Meanwhile** 卡片。打开 "Let people off screen act"。这个开关对所有聊天生效。它需要 **Dashboard** 处于开启状态，因为幕后从它那里读取场景；它还需要有人来行动：一张不在场景中的角色卡，或者 World DM 手册中的一个人。

## 何时运行

当至少有两條新回复到来，并且要么新场景开始，要么故事时钟走过了六个小时，就会在一条回复之后运行一次。一次运行就是一次模型调用。如果你设置了专用模型，它就用那个，否则依次使用 World DM 的、Dashboard 传感器的、Library 的、聊天的、应用的模型。卡片上会写明用的是哪个。"Run a pass now" 会立即运行一次。

一次运行最多请求三个小事件。它会读取刚刚结束的场景、Dashboard 中尚未了结的线索、阵线，以及每个人物在 World DM 记录中最后停在哪里，让事件推动他们向前，而不是重演他们被留下的那一刻。应用会逐一检查：人物必须是聊天认识的人，绝不能是你的角色，也绝不能是场景中的任何人；效果必须来自一个简短的列表。未通过检查的事件会被整体丢弃，日志会说明原因。重复同一个人此前某个事件已说过内容的事件也会被丢弃(“repeats an earlier event”)。如果模型什么都没回答，这次运行会带着更多余量再试一次；失败的一次运行会等待十分钟。

## 卡片显示什么

- **What this card shows**：Nothing（只显示发生了某件事）、Hints（谁和哪里）或 Everything。默认是 Hints，这样故事就不会被你剧透。
- **Off screen so far**：按照该设置所允许的程度显示事件。
- **Log**：每一次运行：为什么运行（场景关闭、时间流逝、手动），模型提供了多少事件、保留了多少、其余为何被丢弃，以及失败时的错误。

## 事件对故事的影响

每个被保留的事件都会成为它所发生在的人以及看到它的人的回忆，而不是其他人的：绝不是你的角色。它按照故事记录（[[litopys]]）的通常规则触及一条回复：当那些人中的一位说话时，或者其中一位在场景中，供旁白或群组回复时。知道这件事的人随后可以提起它、暗示它或据此行动；其他人则不可以。秘密事件还会被标记为 "kept secret"，这样群组回复会被告知是谁在保守它。这些事件不会被复制到 Library 的 Facts 中：每条回复都会从 Meanwhile 文件中读取它们，所以保留它们不花任何代价，并且会随滑动一起消失。提示词中的 "What fired" 面板会像列出任何事实一样列出它们。

如果你关闭幕后，事件会立即停止触及回复。

## 在 Dashboard 的日志中

在宽屏 Dashboard 中，一个角色的 **Journal** 有一个 **Off screen (Meanwhile)** 区域，显示发生在该角色身上的事件，最新的在前，显示程度取决于卡片的设置：在 Hints 下只显示地点和时间，在 Everything 下显示文本，在 Nothing 下什么都不显示。它只读取 Meanwhile 文件；不会向 Dashboard 写入任何内容，所以它会随滑动消失，也不需要额外设置。在手机上不显示 Journal。

## 滑动和删除

一个事件属于它发生之后的那条回复。如果你重新生成那条回复，新版本写入时不会带有该事件；如果你滑动或删除那条回复，那次运行的事件也会一并从故事中消失，下一次运行会从仍然存在的最后一条回复重新读取故事。
