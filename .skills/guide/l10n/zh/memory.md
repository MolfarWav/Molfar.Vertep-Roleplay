# 何种记忆用于何种用途

Roleplay中有多种会“记住”的东西。它们的不同之处在于由谁保存、保存什么以及保存多久。如果角色忘记了某事，本页会告诉你应该使用哪一种。

## 类型

**聊天历史。** 消息本身。模型在其窗口允许的范围内看到尽可能多的近期消息。

**Dashboard**（[[dashboard]]）。按聊天保存，场景的*当前*状态：谁在场、感受、服装、开放任务、每个角色知道什么。它随每次回复而变化。

**Litopys**（[[litopys]]）。按聊天保存，故事的*过去*：每个已结束场景对应一个章节，以及事实列表。这是长聊天在较早消息离开提示后所依赖的内容。

**卡片记忆。** 按角色保存，跨聊天使用：角色从已结束故事中记住的内容、他们的事实、笔记、说过的台词和获得的习惯。它位于卡片编辑器的“Memory”标签页中。你可以导入一个已结束的聊天，查看将要保留的内容，勾选要保留的项，并用一个开关为新聊天关闭某个故事。它有自己的容量（默认Compact 800 token）。它不是卡片文本的一部分，也绝不会出现在导出的卡片中。

**设定集。** 参考条目，在其关键词出现时加入提示，少数条目则始终加入。它们保存世界的规则、地点、人物。可将设定集链接到卡片或群组，或标记为Global以在所有聊天中可用。每个聊天还会获得由World DM撰写的自己的世界设定集（[[world-dm]]）。

**Data Bank**（Tools）。你上传的文本文档（仅限文本格式，每个最多2 MB）。在每条消息中，最相关的段落会被添加。用于较长的参考资料，而不是故事本身。

**作者备注**（聊天顶部，“Note”）。你仅为此聊天撰写的文本，置于你选择的深度和角色中。用于引导：风格提示、情节推动。

**Soul**（[[soul]]）。不是对事件的记忆，而是角色的反应方式；它在游玩过程中从不改变。

## 使用哪种

- “她应该记得昨晚的争吵”：Dashboard短期处理；Litopys长期保存。如果绝对不能丢失，请添加一条置顶事实。
- “她应该在新聊天中记得上一个故事”：使用卡片记忆，或在Canvas上链接聊天，让较早的聊天将其故事作为背景故事带入。
- “世界有一条规则或一个地点”：使用设定集。
- “我希望接下来的回复朝这个方向发展”：使用作者备注，或“Story, move”按钮。
- “我有一份很长的文档”：使用Data Bank。

## 成本

所有这些都会占用提示空间。Canvas的Prompt面板会显示每个部分及其token数，并允许你为一个聊天关闭某些部分。在小型模型上，降低Litopys的“Memory size”，将卡片记忆保持为Compact，并优先使用少量简短的设定集条目。
