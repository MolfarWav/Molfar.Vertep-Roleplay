# 長いチャットとトークンのコスト

何週間も続くチャットは大きくなり、返信のたびにモデルへ送る量が増えます。このページは、返信が遅くなったり高くついたりする人、またはモデルがストーリーの冒頭を忘れてしまう人のためのものです。

## Request size ボタン

デフォルトでは、ウィンドウに余裕がある間はチャット全体が送られます。大きなウィンドウでは、コストは増え続けるので、チャットヘッダーのストーリーツールの隣に **Request size** ボタンがあります（電話ではメニュー内）。直近のリクエストで送られたトークン数、プロバイダーが数えたプロンプト全体、そしてそれを受け取ったモデルが表示されます。押すと、モデル、そのウィンドウ、あなたの上限が表示されます。上限の4分の3未満ではティール、そこから上はアンバー、上限を超えると警告の記号とともに赤になります。キャンバスの Prompt ボードには、リクエストのすべての部分が一覧されます（[[canvas]]）。

返信によってリクエストが上限を超えると、ポップアップが開きます：

- **Yes, continue in a new chat** は、次のチャットをすぐに作成して開きます。
- **Not now** は、リクエストが半分ほど増えるまで、このチャットについてポップアップを隠します。閉じるボタンも Not now として扱われます。
- **Send finished scenes as chapters instead** は、Litopys がオンのときに表示されます（次の節を参照）。

上限はポップアップの下部にあり、Library の歯車 "Litopys settings" の "In the prompt" ブロックにある "Warn me when a request gets big" でも設定できます。選べるのは、モデルのウィンドウの60%（デフォルト）、入力したサイズ（100k など）、または選択したサイズ（16k から 500k）、もしくは never（警告しない）です。すでに上限を超えているチャットは、新しい返信でさらに大きくなるまで、赤いボタンを表示するだけでポップアップは出ません。

記録には独自のサイズがあります。同じブロックの "Memory size" は、デフォルトで Auto（モデルのウィンドウの15%、800から16000トークンの間）です。"Compact" にすると800に保たれます。

## コストを抑えるスイッチ

同じブロックの "Older messages leave the prompt" には、2つの選択肢があります：

- **Only when the window is full**（デフォルト）：ウィンドウに収まる限り、すべてのメッセージが送られます。
- **By scenes**：章がシーンを覆うとすぐに、そのシーンは章に置き換えられます。直近のメッセージだけが一字一句残ります（"Direct messages after the scenes"、2件以上）。最新のシーンにはまだ章がないので、全文が送られます。

"By scenes" は、ある程度の細部を犠牲にします。章は語り直しなので、弱いモデルでは小さなことが失われるかもしれません。絶対に失ってはならない事実は固定してください（[[litopys]]）。ほかの削減方法は次のとおりです：

- キャンバスの Prompt ボード、History カード、Details：直近の N 件のメッセージだけを送る（デスクトップでは、そのチャットだけ）。
- "Memory size" を Compact に下げるか、"Chapters and facts" をオフにする。

## 新しいチャットを始めて、ストーリーを引き継ぐ

区切りのよいところで、古いチャットを引き継ぐ新しいチャットは、短いプロンプトで始まりつつ、何が起きたかを覚えています。

1. チャットで "More" を開き、**Continue in a new chat** を選ぶか、ポップアップで Yes を押します。
2. 新しいチャットがすぐに作成され、開きます。プリセットとその選択、ペルソナ、モデル、エージェントのセット、グループの発言順、World DM の世界を引き継ぎます。
3. 古いストーリーが背景設定として渡されます：章、事実、転換点を、最大3つ前のチャットまで、"Backstory budget" の範囲内で。長い連鎖の古いチャットは捨てられず、1つの圧縮された部分にまとめて入ります（後述）。古いメッセージは送られません。

以前のチャットは、その後自動的に Archive へ移ります（次の節）。このリンクは、キャンバスに描かれるものと同じで、キャンバスで後から変更できます：[[canvas]] を参照してください。別の以前のチャットを選びたい場合は、キャラクターからチャットを始め、"New chat with" の手順で **Continues** メニューを使います。

新しいチャットは、カードの最初の挨拶で開きます。"Edit the first message" を使うと、ストーリーが止まったところから続けられます。

## 多くのチャットにまたがるストーリー

ストーリーは、多くのチャットにわたって続くことがあります。直近の3つの以前のチャットは、これまでどおり章、アーク、事実を提供します。それより古いチャットはすべて、1つの **far** の部分にまとめられ、先頭に置かれます。その中身は、転換点、固定した事実と重要な事実、そして各アークの1行です。この部分は、Litopys がすでに書いたものから組み立てられ、モデルへの追加の呼び出しは行われません。デフォルトでは背景設定の予算の18%を使います（Library、Litopys settings、"In the prompt" の **Share for the far chats**、5から40）。同じブロックの **Turning points shown** は、ストーリー全体で1回の返信に載る転換点の数を決めます（デフォルトは12）。予算が足りない場合、最も古いチャットの行が最初に失われ、転換点は最後に失われます。**What this chat carries** では、これが独立した行 "Far backstory, chats 1-2" として表示されるので、最初のチャットが失われずに残っていることを確認できます。短い連鎖には far の部分はありません。長いストーリーが薄く感じられる場合は、背景設定の予算を上げてください。

圧縮された部分は、小さな細部（マントの色など）を落とします。以下の一字一句の記憶が、それらを戻します。

## 完了したストーリーをアーカイブする

完了したストーリーは **Archive** に移せます。これはチャットの状態であり、移動ではありません。チャットは元の場所にとどまるので、その記憶、キャンバスでのリンク、そこから作られたブックはすべて動き続けます。

- Chats で、チャットを選んで Archive を押します（そのパネルにあるアンバー色のボタン）。または、Select で複数にチェックを入れます。チャット内では、"Manage chat" のメニューにあります。
- アーカイブされたチャットは、一覧とホームから消えます。フィルタの下にあるアンバー色の **Archive** の行でそれらを開き、**Back to chats** で戻ります。
- 読み取り専用で開きます。読む、コピーする、メッセージから枝分かれさせる、エクスポートする、ダッシュボードとライブラリを見る、ことはできますが、送信、スワイプ、編集、削除はできません。下部の場所には **Continue in a new chat** が表示されます。**Unarchive**（そのパネルまたはバナー内）で、通常の状態に戻ります。
- 確認画面では、そのチャットを引き継ぐチャットがまだない場合、**Archive and continue** が提示されます。
- チャットが別のチャットの以前のチャットになると、**自動的に** アーカイブされます。その契機は、キャンバスのリンク、Continue in a new chat、上のポップアップ、または "Continues" での選択です。Undo 付きのトーストでそれが伝えられます。分岐（Branch）は続きではないので、そのままになります。この自動処理をオフにするには、Library の歯車 "Litopys settings" の "Archive the earlier chat when it is continued" を使います。
- 100件以上のメッセージがあり、1週間動きのないチャットには、一覧に "Long chat · archive?" の小さなタグが付き、そのパネルにもヒントが表示されます。あなたの代わりに、何かがアーカイブされることはありません。

アーカイブする理由：以前のチャットはもう変わらないので、その記憶が安定し、それを引き継ぐ新しいチャットは、それを完了したストーリーとして読みます（[[litopys]]）。

## 章から抜け落ちた細部

章は語り直しなので、以前のチャットの小さな細部が章から抜け落ちることがあります。Library の Litopys settings、"In the prompt" にある **Word-for-word memories of earlier chats** のスイッチ（デフォルトでオン）をオンにすると、ほかのチャットを引き継ぐチャットは、いま話されている内容が珍しい単語を共有する場合に、元のメッセージから1つか2つの一節を取り戻せます（[[litopys]]）。以前のチャットは、Archive に移されたときにインデックス化されます。これは単語によるマッチなので、別の言葉で語られた細部は見つかりません。実験的なスイッチ **Also find old chapters by meaning**（デフォルトはオフ）は、埋め込みを使う場合に、そのギャップを少し縮めます。意味によって章を見つけますが、一節は依然として、それ自身の珍しい単語を1つ必要とします。

## ストーリーをブックとして保存する

Library の Litopys で、"Save as a book" を押すと、選んだチャットの章、アーク、事実を Data Bank の棚へコピーします。詳しくは [[memory]] を参照してください。

## モデルが受け取った内容を確認する

キャラクターが何かを忘れた場合は、Canvas > Prompt を開き、"Parts" から "Memory" に切り替えます。どの事実が入り、どれが抜けたのか、その理由が表示されます。チャットヘッダーの **Fired** ボタンは、直近の返信と、チャット全体についてこれを表示します。
