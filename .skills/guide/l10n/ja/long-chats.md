# 長いチャットとトークンコスト

何週間も続くチャットは大きくなり、返信のたびにその多くがモデルへ送られます。このページは、返信が遅くなったり高くなったりする人、モデルが物語の冒頭を忘れてしまう人向けです。

## 「Request size」ボタン

既定では、ウィンドウに空きがある限りチャット全体が送られます。大きなウィンドウではコストが増え続けるため、チャットのヘッダーにはストーリーツールの隣に **Request size** ボタンがあります（スマホではメニュー内）。最後のリクエストが送ったトークン数、プロバイダーが数えたとおりのプロンプト全体、それをどのモデルが受け取ったかが表示されます。押すとモデル、そのウィンドウ、あなたの上限がわかります。上限の4分の3までは青緑、そこからは琥珀色、超えると警告サイン付きの赤になります。Canvas Prompt ボードにはリクエストの各部分が並びます（[[canvas]]）。

返信によってリクエストが上限を超えると、ポップアップが開きます:

- **Yes, continue in a new chat** は次のチャットをすぐに作成して開きます。
- **Not now** は、リクエストが半分増えるまでこのチャットのポップアップを隠します。閉じるのも Not now と同じです。
- **Send finished scenes as chapters instead** は、Litopys がオンのときに表示されます（次のセクション）。

上限はポップアップの下部と、Library の歯車「Litopys settings」、ブロック「In the prompt」、「Warn me when a request gets big」にあります: モデルのウィンドウの60%（既定）、自分で入力するサイズ（100k）か選ぶサイズ（16k〜500k）、または never。すでに上限を超えているチャットは赤いボタンを表示し、新しい返信で増えるまでポップアップは出ません。

記録にも独自のサイズがあります。同じブロックの「Memory size」は既定で Auto です: モデルのウィンドウの15%、800〜16000トークンの範囲。「Compact」は800に保ちます。

## コストを削るスイッチ

同じブロックの「Older messages leave the prompt」には2つの選択肢があります:

- **Only when the window is full**（既定）: 収まる限りすべてのメッセージが送られます。
- **By scenes**: 章がシーンを抱えた時点で、そのシーンは章に置き換えられます。最後のメッセージだけが一言一句そのまま残ります（「Direct messages after the scenes」、2以上）。最新のシーンにはまだ章がないため、そのまま全部送られます。

「By scenes」は細部をいくらか犠牲にします: 章は語り直しなので、弱いモデルは小さなことを失うかもしれません。絶対に失いたくない事実はピン留めしてください（[[litopys]]）。その他の削減:

- Library, Litopys settings, **Direct messages, by size**: 固定の件数の代わりに、トークン数に収まる最新のメッセージを保ちます（最低2メッセージ）。0は件数で数えます（[[litopys]]）。
- Library, Litopys settings, **Leave out what a speaker was not present for**（既定は「Groups only」）: あるキャラクターが話した返信には、そのキャラクターが居なかったシーンの最近のメッセージが入りません（[[litopys]]）。
- Canvas Prompt ボード、履歴カード、Details: 最後のN件のメッセージだけを送ります（デスクトップ、そのチャットのみ）。
- 「Memory size」を Compact に下げる、または「Chapters and facts」をオフにする。

## 新しいチャットを始めて物語を保つ

自然な区切りで、古いチャットを引き継ぐ新しいチャットは小さなプロンプトで始まり、それでも起きたことを知っています。

1. チャットで「More」を開き、**Continue in a new chat** を選ぶか、ポップアップで Yes を押します。
2. 新しいチャットはすぐに作成されて開きます。プリセットとその選択、ペルソナ、モデル、エージェントセット、グループのターン順、World DM のワールドを保ちます。
3. 古い物語を「Backstory budget」の範囲内でバックストーリーとして受け取ります。直近3つの以前のチャットは完全に読み込まれます: 章、事実、転換点。長い連鎖のより古いチャットも捨てられません: それらは1つの凝縮された部分に乗ります（下記参照）。古いメッセージは送られません。

その後、以前のチャットは自動的に Archive へ移ります（次のセクション）。つながりは Canvas が描くもので、Canvas は後からそれを変更できます: [[canvas]]をご覧ください。別の以前のチャットを選ぶには、キャラクターからチャットを始め、「New chat with」ステップの **Continues** メニューを使います。

新しいチャットはカードの最初の挨拶で開きます。「Edit the first message」で、物語が止まったところから続けられます。

## たくさんのチャットからなる物語

物語は多くのチャットにわたって続くことがあります。直近3つの以前のチャットはこれまでどおり章、アーク、事実を渡します。それより古いチャットはすべて1つの **far** 部分に入り、先頭に置かれます: その転換点、ピン留めされた事実と重要な事実、そして各アークにつき1行。この部分は Litopys がすでに書いたものから作られ、追加のモデル呼び出しはなく、既定で Backstory budget の18%を取ります（Library, Litopys settings, 「In the prompt」、**Share for the far chats**、5〜40）。同じブロックの **Turning points shown** は、物語全体を通して1つの返信にいくつの転換点が乗るかを設定します（既定12）。予算が足りない場合、最も古いチャットがまず行を失い、転換点は最後に失われます。**What this chat carries** ではそれ自身の行「Far backstory, chats 1-2」として表示されるので、最初のチャットが失われず保たれたことがわかります。短い連鎖には far 部分はありません。長い物語が薄く感じるなら Backstory budget を上げてください。

凝縮された部分は小さな細部（マントの色など）を落とします。下の一言一句そのままの記憶がそれらを取り戻します。

## 終わった物語をアーカイブする

終わった物語は **Archive** へ送れます。これはチャットの状態であり、移動ではありません: チャットはそのままの場所にとどまるので、その記憶、Canvas 上のリンク、それから作った本はすべて動き続けます。

- Chats でチャットを選び、**Archive** を押す（そのパネルの琥珀色のボタン）、または Select でいくつかチェックします。チャット内では「Manage chat」の下のメニューにあります。
- アーカイブされたチャットは一覧と Home から外れます。フィルターの下の琥珀色の **Archive** 行がそれらを開きます。**Back to chats** で戻ります。
- 読み取り専用で開きます: 読む、コピーする、メッセージから分岐する、エクスポートする、Dashboard と Library を見ることはできますが、送信、スワイプ、編集、削除はできません。その下部には **Continue in a new chat** があります。**Unarchive**（パネルまたはバナー内）で再び通常どおりになります。
- 確認では、まだこのチャットを引き継ぐチャットがない場合、**Archive and continue** が提示されます。
- **自動的に起こる**のは、チャットが別のチャットの以前のチャットになったときです: Canvas 上のリンク、Continue in a new chat、上記のポップアップ、または「Continues」での選択。Undo 付きのトーストがそう告げます。分岐は引き継ぎではなく、そのまま残ります。Library の歯車「Litopys settings」、「Archive the earlier chat when it is continued」でオフにできます。
- 100メッセージ以上で1週間静かなチャットには、一覧に小さな「Long chat · archive?」タグが、そのパネルにヒントが表示されます。あなたの代わりにアーカイブされることはありません。

なぜわざわざ: 以前のチャットはもう変わらないので、その記憶は安定したままになり、それを引き継ぐ新しいチャットは終わった物語として読みます（[[litopys]]）。

## 章が落とした細部

章は語り直しなので、以前のチャットの小さな細部がそこから消えていることがあります。Library, Litopys settings, 「In the prompt」のスイッチ **Word-for-word memories of earlier chats**（既定でオン）は、他のチャットを引き継ぐチャットが、話されている内容が元のメッセージと珍しい単語を共有するとき、元のメッセージの一節を1つか2つ取り戻せるようにします（[[litopys]]）。以前のチャットは Archive へ移るときに索引付けされます。単語で照合するので、別の言葉で語られた細部は見つかりません。実験的なスイッチ **Also find old chapters by meaning**（オフ）は、embeddings を使うときにその差を少し狭めます: 章を意味で見つけますが、一節には依然としてそれ自身の珍しい単語が1つ必要です。

## 物語を本として保存する

Library, Litopys, 「Save as a book」は、選んだチャットの章、アーク、事実を Data Bank の棚にコピーします: [[memory]]をご覧ください。

## モデルが何を受け取ったか確認する

キャラクターが何かを忘れたら、Canvas > Prompt を開き、「Parts」から「Memory」に切り替えます: どの事実が入り、どれが外れ、なぜかを表示します。チャットヘッダーの **Fired** ボタンは、最後の返信とチャット全体についてそれを表示します。
