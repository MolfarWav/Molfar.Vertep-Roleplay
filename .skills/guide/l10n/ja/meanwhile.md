# その裏で：画面の外の暮らし

その裏で（Meanwhile）は、物語が進む間に、その場にいない人たちに行動を起こさせます。Bramが港で馬を売り、Adaが帳簿を隠し、ある戦線が目標へ一歩近づく、といった具合です。これはテスト版で、初期設定ではオフになっています。

## オンにする

チャットの **World** シートを開き、**Meanwhile** カードを見つけます。「Let people off screen act」をオンにします。このスイッチはすべてのチャットに適用されます。Meanwhileはそこからシーンを読み取るため **Dashboard** がオンである必要があり、また行動する誰か、つまりその場にいないキャラクターカードか、World DMの帳簿にいる人物が必要です。

## いつ動くか

パスは、少なくとも二つの新しい返信が来て、さらに新しいシーンが始まったか、物語の時計が六時間進んだときに、返信の後に実行されます。一回のパスは一回のモデル呼び出しです。専用のモデルを設定していればそれを使い、そうでなければ World DM のもの、Dashboard センサーのもの、Library のもの、チャットのもの、アプリのものを使います。どのモデルかはカードに表示されます。「Run a pass now」で即座に一回実行できます。

パスは最大三つの小さな出来事を求めます。アプリはそれぞれを検査します。登場する人たちはチャットが知っている人物でなければならず、あなたのキャラクターであってはならず、その場にいる誰かであってもいけません。そして効果は短いリストの中からでなければなりません。検査に落ちた出来事はまるごと破棄され、ログに理由が記されます。同じ人物についての以前の出来事がすでに述べたことを繰り返す出来事も破棄されます(「repeats an earlier event」)。モデルが何も答えなければ、パスは余裕を持たせてもう一度試みます。失敗したパスは十分間待ちます。

## カードに表示されるもの

- **What this card shows**：Nothing（何かが起きたことだけ）、Hints（誰がどこで）または Everything。初期設定は Hints なので、あなたに物語のネタバレはありません。
- **Off screen so far**：その設定が許す範囲での出来事。
- **Log**：すべてのパスについて、なぜ実行されたか（シーンが閉じた、時間が経った、手動で）、モデルが提示した出来事の数と採用された数、残りが破棄された理由、そして失敗したときのエラー。

## 出来事が物語に与える影響

採用された各出来事は、それが起きた人たちと、それを見た人たちの記憶となり、それ以外の誰のものでもありません。あなたのキャラクターのものには決してなりません。それは物語の記録（[[litopys]]）の通常のルールによって返信に届きます。つまり、それらの人たちの誰かが話すとき、あるいはナレーターやグループの返信のためにそのうちの誰かがその場にいるときです。知っている人はそれを口に出したり、ほのめかしたり、行動に移したりできますが、他の人たちはできません。秘密の出来事は「kept secret」とも印が付けられ、グループの返信には誰がそれを保っているかが伝えられます。出来事は Library の Facts にはコピーされません。返信ごとに Meanwhile ファイルから読み取られるので、保つのにコストはかからず、スワイプとともに消えます。プロンプトの「What fired」パネルには、他の事実と同じように一覧表示されます。

Meanwhileをオフにすると、出来事はすぐに返信へ届かなくなります。

## Dashboardのジャーナルで

ワイドな Dashboard では、キャラクターの **Journal** に **Off screen (Meanwhile)** セクションがあり、そのキャラクターに起きた出来事が新しい順に並びます。カードの設定が許す範囲で表示され、Hints ではどこでいつだけ、Everything では本文、Nothing では何も表示されません。これは Meanwhile ファイルを読むだけで、Dashboard には何も書き込まないので、スワイプとともに消え、追加の設定も要りません。スマートフォンでは Journal は表示されません。

## スワイプと削除

出来事は、それが起きた後の返信に属します。その返信を再生成すると、新しい版はその出来事なしで書かれます。その返信をスワイプまたは削除すると、そのパスの出来事も物語から消え、次のパスはまだ残っている最後の返信から物語を読み直します。
