# Litopys：ストーリーの記録

Litopys（年代記）は、1つのチャットの長期的な記憶です。バックグラウンドでストーリーを読み、終わった各シーンの章と、ストーリーで確定した事実を書きます。チャットがモデルのウィンドウに対して長くなりすぎると、記録がストーリーを前に進めます。長いストーリーに使ってください。開始する必要はありません。

## 章と事実

- **章**は、シーンで何が変わったかを述べるもので、語り直しではありません。次のシーンが始まってから書かれるため、最新のシーンにはまだ章がない場合があります。新しい場所や時間の飛躍でシーンが閉じます。また、メッセージの「More」メニューの Story の下から、連続するメッセージをシーンとして自分でマークすることもできます。
- **事実**とは、真実であり続ける短い文ひとつです：「メドリは市場で翼を隠している。」事実には種類、重み（Everyday、Important、Key）、そしてそれを知っている人物があります。事実は手動で追加、編集、固定、廃止できます。
- **Proposals** は Litopys からの提案です：2つの事実の統合、1つの廃止、言い換え、固定。それぞれを承認または却下します。
- キャラクターがはっきり示す行動も **Habits** として現れることがあり、いくつかのシーンで繰り返されると習慣になります。

## 確認する場所

チャットヘッダーの **Record** を押すと（電話ではメニュー内）、このチャットの記録がサイドパネルに表示されます。レールの **Library** セクションには、すべてのチャットの記録が表示されます。ビューは2種類あります：Overview（タイムライン、キャラクターごとのカード、承認待ちの提案）と Details（タブ：Chapters、Facts、Proposals、Habits、Activity）。Activity タブには Litopys が行ったことが記録され、可能な場合は Undo で元に戻せます。歯車（「Litopys settings」）では、記録の書き方を設定します。

## プロンプトに入るもの

デフォルトでは、記録は自動的に挿入されます。「Memory size」は、記録が使ってよいトークン数を指定します：デフォルトは Auto（モデルのウィンドウの15%。最低800、最大16000）、Compact（800トークン）、または200から16000までの Custom です。Auto では、大きいウィンドウならより多くのストーリーを運べます。小さいモデルでは800付近にとどまります。以前に自分で保存したサイズは、そのまま残ります。すべてが収まる場合は全部送られます。収まらない場合は、シーンにとって最も重要な部分が送られます。小さいモデルには小さいサイズが向いています。「Chapters and facts」をオフにすると、新しい章や事実は作られず、プロンプトに何も追加されなくなります。

古いメッセージがプロンプトから外れるのは、ウィンドウがいっぱいになったときか、章がそれらを覆った後にシーンごとに、のどちらかだけです。どちらにするかは「Older messages leave the prompt」の設定で選びます。

## 意味による一致

メモリは、単語で章と事実を見つけます。埋め込みモデルがあると、意味によっても見つけます。言い回しが違う質問でも、事実に届きます。カード **Matching by meaning**（チャットの記録の一番上、および Canvas > Prompt > Memory にあります）は、現在の状態を示します：オフ、失敗、ベクトルなし、一部完了、完了、別のモデルで作成のいずれかです。モデルの設定は一度だけ、Settings > Memory で行います。デフォルトでは、アプリはまず自分のコンピューター上のモデル（LM Studio または Ollama）を使い、次にキー付きの API 接続、最後に OpenRouter を使います。埋め込みモデルへの呼び出しが一度成功すると（カードのボタンを押すか、返信があると）、エンジンが、すべてのチャットと Data Bank ファイルの不足しているベクトルを、数分ごとの確認で自動的に埋めていきます。300,000トークンを超える分は、ボタンが押されるまで待ちます。Settings > Memory にあるスイッチ **Make vectors by itself** で、これをオフにできます。ボタン **Embed N items** は、まず項目数と、おおよそのトークン数を示し、その場で実行します。新しいシーンは、この設定に関係なく、新しい項目を埋め込みます。埋め込みモデルを変更しても、**Embed again** を押すまで古いベクトルは使われません。Data Bank には独自のカード **Data Bank by meaning** があり、Settings > Data Bank の一番上にあります。ファイルのパッセージとスナップショットのブックに対して同じように動作し、一部だけ対象になっているファイルには「7 of 12 by meaning」と表示されます。

## 提案と整理

「Suggestions」は、デフォルトで「Ask me first」です。すべての固定と言い換えは、あなたの承認を待ちます。静かなオプションでは、固定と言い換えをすぐに適用し、Activity に記録します。廃止と統合は、常にあなたの承認を待ちます。「Tidy facts automatically」は、新しい事実が30件たまるごとに重複と矛盾を探します。その際、60事実ごとに追加のモデル呼び出しが1回かかります。

## 再構築

「Rebuild from scratch」は、メッセージから章と事実をバックグラウンドで書き直します。約30秒ごとにモデル呼び出しが1回行われます。あなた自身の事実、編集済みおよび固定済みの事実、編集済みの章は残ります。新しい記録が準備できるまでは、現在の記録が使われます。閉じたシーンがない場合は、開始を拒否します。

章が書かれた後にメッセージを編集すると、その章は古いものとしてマークされ、書き直されます。
