# Canvas：チャットのリンク、プロンプト、エージェント

Canvas は Roleplay の技術的な作業台です。ボードのある1つの画面で、チャットがどうつながっているか、そして各チャットがモデルに何を送るかを確認し、変更できます。プレイするだけなら必要ありません。ストーリーに続編が必要なとき、返信が予想外だったとき、またはエージェントを作るときに開いてください。

上部の **Board** スイッチでボードを選びます：**Chat links**、**Prompt**、**Agents**、**Agent sets**。レールの Agents 項目は、同じ Canvas を Agents ボードで開きます。前回使ったボードは記憶されます。

## チャットのリンク

チャットの地図です。各チャットはカードとして表示されます。あるチャットから別のチャットへの線は、「このチャットは、そのチャットの続きである」を意味します。前のチャットのストーリーは、後のチャットの返信に背景設定として付いていきます。その量は Library で設定した背景設定の予算の範囲内です。実線は続きを表します。破線は、メッセージから分岐したブランチです。

- ボードに置いていないチャットは、左側のリスト（**Chats**）で待機します。ひとつをボードにドラッグするか、**Put on the board** を使います（**its linked chats** を付けると、チェーン全体を持ってきます）。カードをリストにドラッグし戻すか、**Remove** を使うと、ボードから外れます。チャット自体は Library に残ります。
- **Edit** スイッチをオンにすると、カードを接続または切断できます。ループになるリンク、チャットを自分自身に結ぶリンク、既存のリンクと重複するリンクは拒否され、ボードに理由が表示されます。**Undo** と **Redo** があります。**Fit** はグラフ全体を画面に収めます。
- 電話では、ボードは **View** モードで開き、リンクの **List** が表示されます。グラフの構築は大きい画面の方が簡単ですが、リストでもリンクを編集できます。

Library にあるチャットのマップには同じチェーンが表示されますが、閲覧専用です。その **Edit on canvas** ボタンで、ここに移動できます。

## プロンプト

チャットを選ぶと、そのチャットがモデルに送るリクエストを確認できます。ボードには2つのビューがあります：**Parts** と **Memory**。

- **Parts** は、リクエストのすべての部分を一覧します：メインプロンプト、キャラクターカード、ペルソナ、ロアブックのエントリ、会話例、プリセットのセクション、履歴。それぞれにトークン数と状態が付きます。パーツは、プリセットでオフになっている、このチャットでオフになっている、空である、またはこの種の返信には対象外である、のいずれかになります。プリセットに触れずに、このチャットだけパーツをオフにできます。**Only what is sent** を選ぶと、それ以外は隠れ、合計にはモデルが受け取る量が表示されます。
- **Memory** は、直近の返信でメモリが何を入れたのか、その理由を説明します。詳しい説明は [[memory]] にあります。

直近の返信で発火したものだけを手早く確認するには、チャットヘッダーの **Fired** ボタンを使います。Memory ビューと **Fired** は同じ記録を読み取ります。Fired はチャット全体についても集計します。

## エージェントとエージェントセット

エージェントのフォージです。エージェントを作り、試し、エージェントをセットにまとめます。[[agents]] を参照してください。

## 変わらないもの

Prompt ボードでパーツをオフにすると、そのチャットだけに適用されます。プリセットとカードは変更されません。
