# どのメモリを何に使うか

Roleplayには「記憶する」ものがいくつかあります。それらは、誰が保持するか、何を保持するか、どれくらい続くかが異なります。キャラクターが何かを忘れた場合、このページはどれに手を伸ばすべきかを示します。

## 種類

**チャット履歴。** メッセージ自体。モデルは、ウィンドウが許す限り最近のものを見ます。

**ダッシュボード**（[[dashboard]]）。チャットごと、シーンの*現在の*状態：誰がいるか、感情、服装、開いているクエスト、各キャラクターが知っていること。返信ごとに変わります。

**Litopys**（[[litopys]]）。チャットごと、ストーリーの*過去*：終了したシーンごとの章と事実のリスト。これは、古いメッセージがプロンプトから離れた後に長いチャットが頼るものです。

**カードメモリ。** キャラクターごと、チャット間で：キャラクターが終了したストーリーから覚えていること、事実、メモ、言ったセリフ、獲得した習慣。カードエディタの「メモリ」タブにあります。終了したチャットをインポートし、保持されるものを確認し、保持するものにチェックを入れ、スイッチで1つのストーリーを新しいチャットに対してオフにします。独自のサイズがあります（デフォルトではコンパクト800トークン）。カードテキストの一部ではなく、エクスポートされたカードには決して現れません。

**ロアブック。** キーワードが現れたときにプロンプトに参加する参照エントリ、またはいくつかは常に。世界のルール、場所、人を保持します。ブックをカードまたはグループにリンクするか、グローバルとしてマークしてすべてのチャットに届けます。チャットには、World DMによって書かれた独自のワールドブックもあります（[[world-dm]]）。

**データバンク**（ツール）。アップロードしたテキストドキュメント（テキスト形式のみ、各2 MBまで）。すべてのメッセージで、最も関連性の高いパッセージが追加されます。長い参照資料に使用し、ストーリー自体には使用しません。

**作者のメモ**（チャットヘッダー、「メモ」）。このチャット専用に書くテキスト。選択した深さと役割に配置されます。操縦に使用します：スタイルのヒント、プロットのプッシュ。

**ソウル**（[[soul]]）。イベントの記憶ではなく、キャラクターがどのように反応するかです。プレイ中に変わることはありません。

## どれを使うか

- 「彼女は昨夜の喧嘩を覚えているべきだ」：ダッシュボードが短期的に処理します。Litopysが長期的に保持します。決して失われてはならない場合は、固定された事実を追加します。
- 「彼女は新しいチャットで前のストーリーを覚えているべきだ」：カードメモリ、またはキャンバスでチャットをリンクして、以前のチャットがそのストーリーを背景としてもたらすようにします。
- 「世界にはルールや場所がある」：ロアブック。
- 「次の返信をこの方向に進めたい」：作者のメモ、または「ストーリー、ムーブ」ボタン。
- 「長いドキュメントがある」：データバンク。

## コスト

これらはすべてプロンプト内のスペースを取ります。キャンバスのプロンプトボードには、各部分とそのトークン数が表示され、1つのチャットの部分をオフにできます。小さいモデルでは、Litopysの「メモリサイズ」を下げ、カードメモリをコンパクトに保ち、少数の短いロアブックエントリを優先します。
