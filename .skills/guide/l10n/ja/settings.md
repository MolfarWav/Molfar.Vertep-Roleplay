# Roleplay の設定がある場所

Roleplay には、すべてのための単一の設定ページはありません。設定は、それが変える対象の近くにあり、そのうち2つはメインの Molfar Vertep の設定にあります。このページは探し方の案内です。

## 混同しないよう、2つの設定

- **メインの設定**（ページ全体の歯車）Molfar Vertep の：モデルと接続、プロファイル全体のバックアップ、更新。そこでモデルを選んでテストします。[[vertep:settings]] と [[vertep:models]] を参照してください。そこでスターを付けたモデルは、チャットでのクイックスイッチとして表示されます。
- **Roleplay の設定**：ホームのヘッダーにある "Roleplay settings" ボタン（電話ではメニュー内）。メインの設定にもこのアプリが一覧されます。上部の「アプリの設定」の下でアプリ（そこでの名前は "Vertep"）を押すと、このページが開きます。10のセクションがあります：Appearance、Chat Behavior、Streaming、Themes、Prose Colors、Custom CSS、Card tasks、Import、Data、Guide。上部の検索ボックスで絞り込めます。

各セクションの役割を簡単に示すと、Appearance は言語、フォント、チャットの幅、アバターです。Chat Behavior には、Enter で送信する、削除前に確認する、"Spell check in the message box" と "Autocorrect in the message box" などのスイッチがあります（後の2つは初期状態ではオフです。スペルチェックはつづりの誤った単語に下線を引いて修正候補を示しますが、作り出した名前では赤線だらけになります。自動修正はキーボードに単語を書き換えさせるもので、電話ではアスタリスク、引用符、マクロとぶつかることがあります。どちらもメッセージ欄と拡大エディターに適用されます）。Streaming は、返信を書いている途中から表示するか、書き終わってから表示するかを選びます。Card tasks は、カードにそれ専用のモデルがないときに、カードのヘルパー（"Structure it"、"Fill empty"）が使うモデルを選びます。Import は、プリセット、キャラクター、ロアブック、チャット、バックアップの zip を取り込みます（SillyTavern のプリセットは、その選択肢リストが Choices として、作者の説明が notes として、"do not touch" のブロックがロックされた状態で届きます。Roleplay からエクスポートしたプリセットは、すべての Choices を持って戻ります）。Data は、Roleplay 自身のデータを zip として書き出し、復元します（プロファイル全体は、メインの設定の Backup で保存されます）。Guide は、短いツアーと "What's new" を表示したり隠したりします。

## Roleplay の中の、ほかの場所にある設定

- **Dashboard**：その "Settings" ボタン。Sensor、Event vocabulary、"What the model sees"、"Tune with Molfar" のタブがあります。[[dashboard]] を参照してください。
- **Litopys**：Library の歯車 "Litopys settings"。[[litopys]] を参照してください。
- **World DM**：チャットヘッダーの World シートと、World セクション。"World settings" に DM モデルがあります。[[world-dm]] を参照してください。
- **Agents**：キャンバスの Agents と "Agent sets" のボード、チャットの Agents タブ。[[agents]] を参照してください。
- **プロンプトとサンプリング**：**Presets** セクション（切り替えられるセクション、変数、サンプラー、最終リクエストの確認）と、1つのチャットのためのキャンバスの Prompt ボード。チャットの Preset パネルには、プリセット名の下に "Works with" の行が表示されます。これは、そのプリセットにルールがあるこのチャットの機能（Dashboard、Litopys、World DM、ダイスなど）を示し、そのうちこのチャットでオフになっているものも示します。
- **カード独自の設定**：カードエディタのタブ。色、正規表現、詳細オプションを含みます。[[characters]] を参照してください。
- **ロアブック**：各ブックには独自のルール（スキャンの深さ、サイズの上限、Global のスイッチ）があります。[[memory]] を参照してください。
- **Inbox** には、何があなたを待っているものとして数えられるかを、種類ごとに切り替えるスイッチがあります。

## ツール

**Tools** セクションはタブの行で、Panels（Tool Calling などのプラグインのパネル）、Text & voice、System にまとめられています。

- **Regex**：オンにした場所でのみ働く、検索と置換のスクリプト。
- **Translation**：プロバイダー、2つの言語、自動翻訳モード。開いているチャットも翻訳します。
- **Image Generation**：チャットのモデルがシーンを説明し、画像モデルがそれを描きます。デフォルトではオフです。インタラクティブモードをオンにすると、各プロンプトを先に確認できます。
- **TTS**：返信を読み上げます。デフォルトではオフです。
- **Data Bank**：検索に使うテキストのドキュメント（[[memory]]）。
- **Backgrounds**：チャットの後ろに表示される画像。
- **MCP**：エンジンが共有するツールサーバー。どれもこのアプリではオフで始まります。必要なものだけオンにします。
- **Plugins**：アプリの背後で動くプラグインと、それぞれができることを示します。インストール、有効化、無効化は、ここではなく Molfar Vertep の Plugins ボタンで行います。
- **Tool Calling**（Panels の中）：モデルが書きながらツールを使えるようにします。Dice Roller と Picture は組み込みで、オンにするまでオフのままです。

このほか：**Shortcuts** はクイック返信を保持し、イベントに応じて自動的に実行させることもできます。Themes は配色を即座に変え、Prose Colors は台詞と地の文の色を変え、Custom CSS は最後に適用されます。1つのチャットには独自の CSS も設定できます。チャットで **More** > **Chat CSS** を開きます。入力中にすぐ反映され、そのチャットだけに適用されます。グローバルの Custom CSS やキャラクターの CSS よりも優先されます。
