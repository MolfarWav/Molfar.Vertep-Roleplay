# Roleplay：概要

Roleplayは Molfar Vertep のストーリーアプリです。キャラクターカードを保管し、それらのキャラクターとチャットでプレイし、アプリにシーンを追跡させ、物語を記憶させ、あなたの周りの世界を動かせます。このページは全体の地図です。アプリ自身の **Help**（レール内）には、ほぼすべての画面について短い記事があります。このガイドでは、各部分がどう組み合わさるかを説明します。モデルと接続はここではなく、メインの設定で行います：[[vertep:models]] を参照してください。

## 何がどこにあるか

左側のレール（スマートフォンでは画面下部のタブバー）が、セクションをまとめています：

- **Home** と **Chats**：中断したところから再開するか、任意のチャットを開きます。
- **Characters**、**Groups**、**Marketplace**、**Personas**：人物に関するセクションです。[[characters]] を参照してください。
- **Lorebooks**、**Library**、**Canvas**、**World**、**Agents**：ストーリーの記憶と仕組みです。[[memory]]、[[litopys]]、[[canvas]]、[[world-dm]]、[[agents]] を参照してください。
- **Presets**：モデルへのリクエストがどのように組み立てられるか。
- **Shortcuts** と **Tools**：クイック返信、正規表現、翻訳、画像、音声、Data Bank など。[[settings]] を参照してください。
- 下部の **Inbox** と **Help**。Inbox には、あなたの対応を待っているものが並びます：失敗したバックグラウンドの処理、Library の提案、提案されたソウルなど。

Roleplay 自体の設定にはレールの項目がありません。ホームのヘッダーにある "Roleplay settings" ボタンから開きます（スマートフォンではメニュー内）。

## チャットの中

チャットヘッダーには、ストーリーのツールがあります：**Note**（作者のメモ）、**Fired**（プロンプトに入った内容。[[memory]] を参照）、**Record**、**World**。その隣のピルを開くと、このチャットの Preset、Persona、Model、Agents のタブが開きます。すべてのメッセージの "More" ボタンはそのメッセージへの操作を開き、メッセージボックスの横の "+" メニューには Polish、"Regenerate with a hint"、Stage direction、画像生成などがあります。

ストーリーを見守る3つのヘルパーは、追加のモデル呼び出しを使うので、知っておくと役立ちます：

- **Dashboard** は各シーンを読み取ります：[[dashboard]]。入力は1つで、キャラクターの [[soul]] です。
- **Litopys** は章と事実を書きます：[[litopys]]。
- **World DM** は人物と場所の記録帳を保持します：[[world-dm]]。

## このガイドのページ

- [[first-story]]：何もない状態から最初の返信まで。小さいモデルや遅いモデルで何をオフにすべきか。
- [[characters]]：カード、カードエディター、ペルソナ、グループ、インポート。
- [[soul]]、[[dashboard]]、[[litopys]]、[[world-dm]]、[[agents]]：ストーリーの仕組み。
- [[memory]]：何のためにどの種類の記憶を使うか。
- [[canvas]]：チャットのリンク、プロンプトボード、エージェントフォージ。
- [[long-chats]]：長いチャットが遅く、高くなる理由、それを抑える方法、ストーリーを新しいチャットへ運ぶ方法。
- [[settings]]：各設定がどこにあるか。

Molfar Vertep 自体が初めての方は、[[vertep:first-steps]] と [[vertep:glossary]] から始めてください。
