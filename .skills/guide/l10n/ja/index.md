# Roleplay：概要

Roleplay は Molfar Vertep のストーリーアプリです。キャラクターカードを保管し、そのキャラクターとチャットをプレイし、アプリにシーンを追跡させ、物語を記憶させ、あなたの周りの世界を動かすことができます。このページは全体の地図です。アプリ独自の**Help**（レール内）には、ほぼすべての画面について短い記事があります。このガイドでは、各パーツがどう組み合わさるかを説明します。モデルと接続はここではなく、メインの設定で行います：[[vertep:models]] を参照してください。

## どこに何があるか

左側のレール（電話では画面下部のタブバー）がセクションをまとめています：

- **Home** と **Chats**：途中から再開するか、任意のチャットを開きます。
- **Characters**、**Groups**、**Marketplace**、**Personas**：人物に関するセクションです。[[characters]] を参照してください。
- **Lorebooks**、**Library**、**Canvas**、**World**、**Agents**：ストーリーの記憶と仕組みです。[[memory]]、[[litopys]]、[[canvas]]、[[world-dm]]、[[agents]] を参照してください。
- **Presets**：モデルへのリクエストがどのように組み立てられるか。
- **Shortcuts** と **Tools**：クイック返信、正規表現、翻訳、画像、音声、Data Bank など。[[settings]] を参照してください。
- 下部の **Inbox** と **Help**。Inbox には、あなたの対応を待っているものが並びます：失敗したバックグラウンドジョブ、Library の提案、提案されたソウル。

Roleplay 自体の設定にはレール項目がありません。ホームヘッダーの「Roleplay settings」ボタン（電話ではメニュー内）から開きます。

## チャットの中

チャットヘッダーにはストーリーのツールがあります：**Note**（作者のメモ）、**Fired**（プロンプトに入ったもの。[[memory]] を参照）、**Record**、**World**。その隣のピル型ボタンは、このチャットの Preset、Persona、Model、Agents のタブを開きます。すべてのメッセージの「More」ボタンはそのアクションを開き、メッセージボックスの横の「+」メニューには、Polish、Regenerate with a hint、画像生成などがあります。

3つのヘルパーがストーリーを見守り、追加のモデル呼び出しを使うので、次の役割を知っておくと便利です：

- **Dashboard** は各シーンを読み取ります：[[dashboard]]。入力はひとつで、キャラクターの [[soul]] です。
- **Litopys** は章と事実を書きます：[[litopys]]。
- **World DM** は人物と場所の帳簿を保持します：[[world-dm]]。
