# Roleplay：概要

RoleplayはMolfar Vertepのストーリーアプリです：キャラクターカードを保持し、それらとチャットをプレイし、アプリにシーンを追跡させ、ストーリーを記憶させ、周りの世界を実行させます。このページはマップです。アプリ独自の**ヘルプ**（レール内）には、ほぼすべての画面の短い記事があります。このガイドでは、パーツがどのように組み合わさるかを説明します。モデルと接続はここではなく、メイン設定で設定します：[[vertep:models]] を参照。

## 場所

左側のレール（電話では下部のタブバー）はセクションをグループ化します：

- **ホーム**と**チャット**：中断した場所から続けるか、任意のチャットを開きます。
- **キャラクター**、**グループ**、**マーケットプレイス**、**ペルソナ**：人々。[[characters]] を参照。
- **ロアブック**、**ライブラリ**、**キャンバス**、**ワールド**、**エージェント**：ストーリーの記憶と機構。[[memory]]、[[litopys]]、[[world-dm]]、[[agents]] を参照。
- **プリセット**：モデルへのリクエストの構築方法。
- **ショートカット**と**ツール**：クイック返信、正規表現、翻訳、画像、音声、データバンクなど。[[settings]] を参照。
- 下部の**受信箱**と**ヘルプ**。受信箱には、あなたを待っているものがリストされます：失敗したバックグラウンドジョブ、ライブラリの提案、提案されたソウル。

Roleplay独自の設定にはレール項目がありません。ホームヘッダーの「Roleplay設定」ボタン（電話ではメニュー内）で開きます。

## チャット内

チャットヘッダーにはストーリーツールがあります：**メモ**（作者のメモ）、**ロア**、**記録**、**ワールド**。その隣のピルは、このチャットのプリセット、ペルソナ、モデル、エージェントのタブを開きます。すべてのメッセージの「詳細」ボタンはそのアクションを開き、メッセージボックスの横の「+」メニューには、磨き、ヒント付き再生成、画像生成などがあります。

3つのヘルパーがストーリーを監視し、追加のモデル呼び出しがかかるため、知っておく価値があります：

- **ダッシュボード**は各シーンを読み取ります：[[dashboard]]、1つの入力、キャラクターの [[soul]] 付き。
- **Litopys**は章と事実を書きます：[[litopys]]。
- **World DM**は人と場所のブックを保持します：[[world-dm]]。
