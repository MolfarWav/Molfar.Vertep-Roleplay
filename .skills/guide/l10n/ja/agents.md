# エージェントとエージェントフォージ

エージェントは、カードとワイヤーから組み立てる小さなヘルパーです。返信の前後で、あなたが選んだ方法でチャットの一部を読み取り、モデルに短い質問を1つ以上することがあります。自分のメモを保持し、何かを表示します：返信の下のメモ、タップするボタン、メーター、マップ、または次の返信へのヒント。たとえば、次に取る3つの提案された行動、緊張メーター、訪れた場所のマップなどです。このページは、そうした追加機能を使いたい人向けです。ヘルプには、エディタについての記事が3件あります：「Agent editor: how an agent works」、「Agent editor: the cards」、「Agent editor: three ready agents」。

## エージェントの構成要素

エージェントはコードではなくデータです。エディタでは、**ワイヤー**で結ばれた**カード**のボードとして表示されます：

- **Input** カードは、エージェントが読んでよいものを指定します（最後の返信、チャット履歴、キャラクターカード、ペルソナ、作者のメモ、Litopysの事実、ロアブックのエントリ）；
- **Ask the model** カードは、モデルに1つの質問を出し、回答を自由記述、はい/いいえ、または名前付きのいくつかのフィールドとして受け取ります；
- ロジックのカード、およびモデルを使わずコードで動くカード：ダイス、行の選択、テキストの切り出しや抽出；
- **Script** カード：あなたが書く数行のJavaScriptです。`(input, seed)` を受け取り、単純なオブジェクトを返します。入力と出力には型があります。エンジンのサンドボックス内で動き（時計、インターネット、ファイルはなし。約0.5秒と16 MBまで）、エンジンのバージョン1.10.1以降が必要です。古いエンジンでは、エージェントが単純なメッセージとともに失敗します；
- エージェント自身の**メモリ**のカード（数値、テキスト、はい/いいえ、リスト）。チャットごとに保持され、ダッシュボードとは別です；
- 結果を表示する **Output** カード：「A note under the reply」、「Buttons to tap」、状態値、または次のプロンプトに入れるヒント。

**パネル**（メーター、カウンター、テーブル、タイルのボード）は、エージェントが保持している内容を表示します。パネルの中では何も実行されず、そのボタンはメッセージボックスにテキストを入れるだけです。

実行されるタイミングは「レーン」で決まります。エージェントのファイルには開始時のレーンが書かれていて、各チャットはエージェントを別のレーンへ移せます（チャットの Agents タブ、またはキャンバスの「Agent sets」ボード）。レーンは4つあります：

- **Before the reply**：返信はエージェントを待ち、エージェントが残したヒントはその返信にそのまま入ります。待ち時間はすべての返信に加わるので、短い質問を1つか2つにとどめてください。エージェントの行にある Wait スイッチをオフにすると待ちがなくなり、エージェントは返信と並行して動きます。
- **Beside the reply**：返信と同時に動き、待ち時間は加わりません。ただし、併走する返信にヒントを入れることはできません（メモ、ボタン、パネルは使えます）。
- **After the reply**：メモ、トラッカー、メーターに通常使うレーンです。
- **By hand**：その行の実行ボタンを押したときだけ動きます。

レーンに加えて、エージェントは N 回ごとの返信に一度、または選んだ語が現れたときだけ動くこともできます。

## 既製のエージェント

キャンバスの Agents ボードで "New agent" を押します（レールの **Agents** 項目でこのボードが開きます）。"Empty agent" は入力とメモを1つずつ用意します。"Start from a ready agent" では、6つの動くエージェントから選べます：次の行動、ペーシングの促し、ストーリーマップ、シーンの要約、テリトリーボード、緊張メーター。"Drafts" の下には、Molfar があなたのワークスペースに書いたエージェントがあります（"Drafts from Molfar"）。

## エディタ

編集は、入力を止めてから少し後に下書きとして保存されます。タブは3つ：Card（選択中のカード）、Agent（名前、実行タイミング、メモリ、パネル）、Try（試行）。チェックには "Passes the check"、問題と警告の数、"N model calls per run" が表示されます。問題が残っている間はインストールできません。"Export as a file" は、共有できる1つのファイルを保存します。チャットの "Install and manage agents..." シートには、ファイルを取り込む "Install an agent file" があります。

## 試行

Try タブは、何も変更せずに架空のターンを1つ実行します。入力を変えると、ボード上のワイヤーで何が動くかがわかります。モデルがない場合、各 "Ask the model" カードは編集できる回答例を使います。"A real chat" でチャットを選び、"Fill from this chat" を押すと、エージェントが実際に受け取る内容を読み込めます。"Run with the model" は、実際のモデルに実際の質問を投げます：最大 N 回の呼び出し、実際のトークン。チャットにもエージェントにも何も保存されません。

## インストール、許可、チャットでオンにする

1. "Install" を押します（インストール済みエージェントの変更版は "Update"。変更したい場合は "Edit a copy" を使います）。
2. 一度許可します："Review permissions" を開き、"Allow all" を押すか、行ごとに許可します。すべての行がオンになったときに動きます。さらに権限を求める更新では、新しい許可を待ちます。Script カードは "Run its own small program" を求めます。許可する前に、権限の一覧で "Read the code" を押すとそのコードを見られます。更新でコードが変わった場合は、権限を改めて求められます。
3. チャットに追加します。チャットヘッダーのピルで **Agents** タブを開きます："In this chat" には動いているエージェントが、"Installed" には残りが並びます（追加するものを1つ選びます）。各行からは、今すぐ再実行、削除、またはその返信の待ちを止めることができます。新しいチャットには、エージェントを追加するかセットを選ぶまで何もありません。

**セット**は、名前を付けたエージェントの一覧です（"Save this chat's list as a set"。"Make default" を押すと新しいチャットに適用されます）。キャンバスの "Agent sets" ボードには、各セットの時間と呼び出し回数のコストが表示され、すべてのエージェントのメモを隠す "Agents' notes in chats" スイッチがあります。各エージェントの結果の表示先は、チャットの Agents タブで、そのエージェントに合う候補の中から変更できます。

各 "Ask the model" カードは、1回の実行につき1回の呼び出しです。エディタにその回数が表示されます。"Every Nth reply" を使うと、コストを分けられます。
