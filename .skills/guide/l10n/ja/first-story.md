# 最初のストーリー

これは、空のRoleplayから実行中のストーリーまでの最短経路であり、驚かないように自動的に起こることのリストです。最初にモデル接続が必要です：[[vertep:models]] を参照してください。

## 手順

1. **カードを入手します。** ホームで「新しいキャラクター」を押して作成するか、「カードをインポート」でファイルからPNGまたはJSONカードを取り込みます。マーケットプレイスセクションを検索したり、「Molfarと共に」を押してMolfarにアイデアからカードの下書きを依頼したりすることもできます。[[characters]] を参照。
2. **保存します。** カードエディタは、「変更を保存」を押すまで編集を下書きに保持します。
3. **ペルソナを選択します**（あなたが演じる人）ペルソナセクションで、またはデフォルトのままにします。「このペルソナを使う」でデフォルトになります。
4. **チャットを開始します。** カードで「新しいチャット」を押します。チャットはカードの最初のメッセージで開きます。
5. **モデルを確認します。** チャットヘッダーのピルにはモデルタブがあります。そこでモデルを選択すると、このチャットのみが変更されます。
6. **書きます。** 各返信の下で、他のバージョン（スワイプ）をめくることができます。最後のバージョンの右矢印は新しいものを要求します。指示付きで返信をやり直すには、「+」メニューの「ヒント付きで再生成」を使用します。メッセージの「詳細」ボタンでは、編集、フォーク、プロンプトのぞき見などが提供されます。

## 自動的に実行されるもの

チャットに返信があると、バックグラウンドヘルパーが動作し、それぞれに独自のモデル呼び出しがあります：

- ダッシュボードは各返信の後にシーンを読み取ります（[[dashboard]]）。
- Litopysはシーンが閉じたときに章を書きます（[[litopys]]）。
- World DMは、最低のアクティブレベル（クロニクラー）で、このチャットのブックに人と場所を記録します（[[world-dm]]）。
- ソウルのないカードには、自動的にソウルが提案されます（[[soul]]）。

これらのジョブの失敗は受信箱にリストされます。

## モデルが小さい、遅い、または呼び出しごとに有料の場合

最も安価な節約方法、順番に：

1. ダッシュボードの「設定」で、モードを「手動」に設定します（その後、更新を押したときにのみ更新されます）、または小さなモデルを「センサーモデル」として選択します。
2. ライブラリの「Litopys設定」で、「メモリサイズ」を下げるか、「章と事実」をオフにします。
3. ワールドシートで、「オフ」レベルを選択します（シーンが新しい場所に名前を付けたときに小さな呼び出しが発生します）、または安価な「DMモデル（すべてのチャット）」を選択します。
4. ダッシュボード設定で、「キャラクターを自動的に評価」をオフにします。
5. キャンバスでは、プロンプトボードに次のリクエストのすべての部分とそのトークンが表示され、1つのチャットの部分をオフにできます。

コンテキストウィンドウが小さい無料モデルは、手動ダッシュボードとコンパクトメモリで最適に動作します。
