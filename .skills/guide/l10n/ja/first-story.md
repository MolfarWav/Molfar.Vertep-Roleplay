# 最初のストーリー

これは、空の Roleplay から動くストーリーまでの最短の道筋であり、何も驚かないように、自動的に起こることの一覧でもあります。まずモデルへの接続が必要です：[[vertep:models]] を参照してください。

## 手順

1. **カードを用意します。** ホームで "New character" を押して自分で書くか、"Import card" で PNG または JSON のカードをファイルから取り込みます。Marketplace セクションを検索することもできますし、"With Molfar" を押して、アイデアからカードの下書きを Molfar に頼むこともできます。[[characters]] を参照してください。
2. **保存します。** カードエディタは、"Save changes" を押すまで編集を下書きとして保持します。
3. **ペルソナを選びます**（あなたが演じる人物）。Personas セクションで選ぶか、既定のままにします。"Use this persona" を押すと既定になります。
4. **チャットを始めます。** カードの "New chat" を押します。チャットは、カードの最初のメッセージで開きます。
5. **モデルを確認します。** チャットヘッダーのピルには Model タブがあります。そこでモデルを選ぶと、このチャットだけが変わります。
6. **書きます。** 各返信の下で、ほかのバージョン（スワイプ）をめくれます。最後のバージョンの右矢印を押すと、新しいものが生成されます。方向性を指定して返信をやり直すには、"+" メニューの "Regenerate with a hint" を使います。メッセージの "More" ボタンには、編集、フォーク、プロンプトの確認などがあります。

## 自動で動くもの

チャットに返信が入ると、バックグラウンドのヘルパーが働き始めます。それぞれが独自のモデル呼び出しを持ちます：

- ダッシュボードは、返信のたびにシーンを読み取ります（[[dashboard]]）。
- Litopys は、シーンが閉じると章を書きます（[[litopys]]）。
- World DM は、最も低い有効レベル（Chronicler）で、このチャットのブックに人物と場所を記録します（[[world-dm]]）。
- ソウルのないカードには、ソウルが自動的に提案されます（[[soul]]）。

これらの処理の失敗は、受信箱に一覧されます。

## モデルが小さい、遅い、または呼び出しごとに課金される場合

節約効果の大きいものから順に：

1. ダッシュボードの "Settings" でモードを "Manual" に設定します（この場合、Refresh を押したときだけ更新されます）。あるいは、小さなモデルを "Sensor model" として選びます。
2. ライブラリの "Litopys settings" で "Memory size" を下げるか、"Chapters and facts" をオフにします。
3. ワールドシートで "Off" レベルを選びます（シーンが新しい場所に名前を付けたときは、依然として小さな呼び出しが行われます）。または、安価な "DM model (all chats)" を選びます。
4. ダッシュボードの設定で、"Rate characters automatically" をオフにします。
5. キャンバスでは、Prompt ボードに次のリクエストのすべての部分とそのトークン数が表示され、1つのチャットについて部分ごとにオフにできます。

長くなったストーリーには、別の対策が必要です：[[long-chats]] を参照してください。

コンテキストウィンドウの小さい無料モデルには、Manual のダッシュボードと Compact のメモリの組み合わせが最も合います。
