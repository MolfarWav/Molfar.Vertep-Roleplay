# Roleplay 설정이 있는 곳

Roleplay에는 모든 것을 위한 단일 설정 페이지가 없습니다. 설정은 그것이 바꾸는 것 근처에 있고, 두 개는 기본 Molfar Vertep 설정에 있습니다. 이 페이지는 찾아보기입니다.

## 두 가지 설정, 혼동하지 마세요

- **기본 설정** Molfar Vertep(전체 페이지의 톱니): 모델과 연결, 전체 프로필 백업, 업데이트. 여기서 모델을 고르고 테스트하세요. [[vertep:settings]]와 [[vertep:models]] 참조. 거기서 별표한 모델이 채팅에서 빠른 전환으로 나타납니다.
- **Roleplay 설정**: 홈 헤더의 "Roleplay 설정" 버튼(휴대폰에서는 메뉴 안). 아직 기본 설정 안에는 나열되지 않으므로 Roleplay 자체에서 찾으세요. 열 개 구역이 있습니다: 모양, 채팅 동작, 스트리밍, 테마, 산문 색상, 사용자 지정 CSS, 카드 작업, 가져오기, 데이터, 가이드. 위쪽 검색창이 필터링합니다.

구역이 하는 일, 간단히: 모양은 언어, 글꼴, 채팅 너비, 아바타; 채팅 동작은 Enter로 보내기, 삭제 확인 같은 스위치; 스트리밍은 답장을 쓰는 대로 보여줄지 끝났을 때 보여줄지 선택; 카드 작업은 카드에 자체 모델이 없을 때 카드 도우미("구조화하기", "빈칸 채우기")가 쓸 모델을 고름; 가져오기는 프리셋, 캐릭터, 로어북, 채팅, 백업 zip을 들여옴(SillyTavern 프리셋은 선택 목록이 선택지로, 작성자의 설명이 메모로, "건드리지 말 것" 블록이 잠긴 채로 들어옴; Roleplay에서 내보낸 프리셋은 모든 선택지와 함께 돌아옴); 데이터는 Roleplay 자체 데이터를 zip으로 내보내고 복원함(전체 프로필은 기본 설정의 백업이 저장); 가이드는 짧은 투어와 "새 소식"을 보이거나 숨김.

## Roleplay의 다른 곳에 사는 설정

- **대시보드**: "설정" 버튼, 탭 센서, 사건 어휘, "모델이 보는 것", "Molfar로 조율". [[dashboard]] 참조.
- **Litopys**: 라이브러리의 톱니 "Litopys 설정". [[litopys]] 참조.
- **World DM**: 채팅 헤더의 월드 시트와 월드 구역. "월드 설정"이 DM 모델을 담습니다. [[world-dm]] 참조.
- **에이전트**: 캔버스의 에이전트와 "에이전트 세트" 보드, 채팅의 에이전트 탭. [[agents]] 참조.
- **프롬프트와 샘플링**: **프리셋** 구역(전환할 구역, 변수, 샘플러, 최종 요청 미리보기)과 채팅 하나용 캔버스의 프롬프트 보드. 채팅의 프리셋 패널은 프리셋 이름 아래에 "함께 작동" 줄을 보여 줍니다. 이 채팅의 기능 중 프리셋에 규칙이 있는 것(대시보드, Litopys, World DM, 주사위 등)과 그중 이 채팅에서 꺼져 있는 것입니다.
- **카드 자체**: 편집기 탭, 색상, 정규식, 고급 옵션 포함. [[characters]] 참조.
- **로어북**: 각 책에 자체 규칙(스캔 깊이, 크기 상한, 전역 스위치)이 있습니다. [[memory]] 참조.
- **받은 편지함**에는 무엇이 당신을 기다리는 것으로 셀지 종류별 스위치가 있습니다.

## 도구

**도구** 구역은 탭 행이며 패널(도구 호출 같은 플러그인 패널), 텍스트 및 음성, 시스템으로 묶입니다.

- **정규식**: 켠 곳에서만 작동하는 찾아 바꾸기 스크립트.
- **번역**: 제공자, 언어 두 개, 자동 번역 모드. 열린 채팅도 번역합니다.
- **이미지 생성**: 채팅 모델이 장면을 설명하고 이미지 모델이 그립니다. 기본 꺼짐. 대화형 모드를 켜면 각 프롬프트를 먼저 확인합니다.
- **TTS**: 답장을 소리 내어 읽습니다. 기본 꺼짐.
- **데이터 뱅크**: 검색에 쓰는 텍스트 문서([[memory]]).
- **배경**: 채팅 뒤의 그림.
- **MCP**: 엔진이 공유하는 도구 서버. 각각 이 앱에서 꺼진 채로 시작합니다. 필요한 것을 켜세요.
- **플러그인**: 앱 뒤에서 어떤 플러그인이 돌고 각각 무엇을 할 수 있는지 보여줍니다. 설치, 활성화, 비활성화는 여기가 아니라 Molfar Vertep의 플러그인 버튼에서 합니다.
- **도구 호출**(패널 안): 모델이 쓰는 동안 도구를 쓰게 합니다. 주사위 굴림과 그림이 내장되어 있으며 켜기 전까지 꺼져 있습니다.

또한: **바로가기**는 빠른 답장을 담고 이벤트에서 스스로 실행될 수 있습니다. 테마는 팔레트를 즉시 바꾸고, 산문 색상은 대사와 서술을 다시 칠하고, 사용자 지정 CSS는 마지막에 적용됩니다.
