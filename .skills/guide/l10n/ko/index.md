# Roleplay: 개요

Roleplay는 Molfar Vertep의 스토리 앱입니다. 캐릭터 카드를 보관하고, 캐릭터와 채팅하며, 앱이 장면을 추적하고 이야기를 기억하고 주변 세계를 운영하도록 합니다. 이 페이지는 지도입니다. 앱 자체의 **Help**(레일 안에 있음)에는 거의 모든 화면에 대한 짧은 글이 있고, 이 가이드는 각 부분이 어떻게 맞물리는지 설명합니다. 모델과 연결은 여기서가 아니라 기본 Settings에서 설정합니다: [[vertep:models]]를 참고하세요.

## 무엇이 어디에 있는지

왼쪽의 레일(휴대폰에서는 하단의 탭 바)이 섹션을 묶습니다:

- **Home**과 **Chats**: 멈춘 곳에서 계속하거나 아무 채팅이나 엽니다.
- **Characters**, **Groups**, **Marketplace**, **Personas**: 사람들. [[characters]]를 참고하세요.
- **Lorebooks**, **Library**, **Canvas**, **World**, **Agents**: 이야기의 기억과 장치. [[memory]], [[litopys]], [[canvas]], [[world-dm]], [[agents]]를 참고하세요.
- **Presets**: 모델로 가는 요청이 어떻게 구성되는지.
- **Shortcuts**와 **Tools**: 빠른 답장, 정규식, 번역, 그림, 음성, Data Bank 등. [[settings]]를 참고하세요.
- 맨 아래의 **Inbox**와 **Help**. Inbox는 여러분을 기다리는 것들을 나열합니다: 실패한 백그라운드 작업, Library 제안, 제안된 soul.

Roleplay 자체 설정에는 레일 항목이 없습니다. Home 헤더의 "Roleplay settings" 버튼(휴대폰에서는 메뉴 안)으로 엽니다.

## 채팅 안에서

채팅 헤더에는 스토리 도구가 있습니다: **Note**(작가 노트), **Fired**(프롬프트에 들어간 것, [[memory]] 참고), **Record**, **World**. 옆의 pill은 이 채팅의 Preset, Persona, Model, Agents 탭을 엽니다. 모든 메시지의 "More" 버튼은 해당 메시지의 동작을 열고, 메시지 상자 옆의 "+" 메뉴에는 Polish, 힌트와 함께 Regenerate, Stage direction, 이미지 생성 등이 있습니다.

세 가지 도우미가 이야기를 지켜보며 추가 모델 호출을 소모하므로 알아두면 좋습니다:

- **Dashboard**는 각 장면을 읽습니다: [[dashboard]], 입력은 하나, 캐릭터의 [[soul]]입니다.
- **Litopys**는 챕터와 사실을 씁니다: [[litopys]].
- **World DM**은 사람과 장소의 책을 유지합니다: [[world-dm]].

## 이 가이드의 페이지들

- [[first-story]]: 아무것도 없는 상태에서 첫 답장까지, 그리고 작거나 느린 모델에서 무엇을 꺼야 하는지.
- [[characters]]: 카드, 카드 편집기, 페르소나, 그룹, 가져오기.
- [[sprites]]: 채팅 위의 스프라이트, 그룹이나 내레이터를 위한 여러 창, 비주얼 노벨 느낌.
- [[soul]], [[dashboard]], [[litopys]], [[world-dm]], [[agents]]: 스토리 장치.
- [[places-map]]: 채팅의 장소들을 도로와 직접 넣은 그림과 함께 보여주는 떠 있는 지도.
- [[places-map-levels]]: 한 채팅에 여러 지도(국가, 도시, 던전)를 넣고 이미지 모델로 지도를 그리기.
- [[memory]]: 어떤 종류의 기억을 무엇에 쓸지.
- [[canvas]]: 채팅 링크, 프롬프트 보드, 에이전트 포지.
- [[long-chats]]: 긴 채팅이 왜 느려지거나 비싸지는지, 무엇이 그것을 줄이는지, 이야기를 새 채팅으로 옮기는 방법.
- [[settings]]: 각 설정이 어디에 있는지.
