# 에이전트와 에이전트 제작소

에이전트는 카드와 연결선으로 만드는 작은 도우미입니다. 답장이 끝난 뒤 채팅의 일부를 읽고, 모델에게 짧은 질문을 하나 이상 던지고, 자체 메모를 보관한 다음, 무언가를 보여줍니다. 답장 아래의 메모, 누르는 버튼, 수치 표시, 지도, 또는 다음 답장을 위한 힌트 같은 것입니다. 예: 추천 다음 행동 세 가지, 긴장도 표시, 방문한 장소 지도. 이 페이지는 그런 추가 기능을 원하는 분을 위한 것입니다. 아직 에이전트에 대한 도움말 문서는 없습니다.

## 에이전트의 구성 요소

에이전트는 코드가 아니라 데이터입니다. 편집기에서는 **카드**들이 **연결선**으로 이어진 보드입니다.

- **입력** 카드는 에이전트가 읽을 수 있는 것을 정합니다(마지막 답장, 채팅 기록, 캐릭터 카드, 페르소나, 작가의 메모, Litopys 사실, 로어북 항목).
- **모델에게 질문** 카드는 모델에게 질문 하나를 던지고 답을 자유 텍스트, 예/아니요, 또는 몇 개의 이름 붙은 필드로 받습니다.
- 논리 카드, 그리고 모델 없이 코드로 동작하는 카드: 주사위, 문장 고르기, 텍스트 자르기나 추출.
- 에이전트 자신의 **메모리**(숫자, 텍스트, 예/아니요, 목록)용 카드. 채팅마다 보관되며 대시보드와는 별개입니다.
- 결과를 보여주는 **출력** 카드: "답장 아래의 메모", "누르는 버튼", 상태 값, 또는 다음 프롬프트에 넣는 힌트.

**패널**(수치 표시, 카운터, 표, 타일 보드)은 에이전트가 보관한 것을 표시합니다. 패널에서는 아무것도 실행되지 않으며, 패널의 버튼은 메시지 상자에 텍스트를 넣을 뿐입니다.

실행 시점은 에이전트별로 설정합니다: 답장 전, 답장과 함께, 답장 후, 또는 수동으로; N번째 답장마다; 또는 선택한 단어가 나타날 때만.

## 준비된 에이전트

**캔버스**(레일의 **에이전트** 항목으로 엽니다)의 에이전트 보드에서 "새 에이전트"를 누르세요. "빈 에이전트"는 입력 하나와 메모 하나를 줍니다. "준비된 에이전트에서 시작"은 작동하는 여섯 가지를 제공합니다: 다음 행동, 흐름 조절, 이야기 지도, 장면 요약, 영역 보드, 긴장도 표시. "초안" 아래에는 Molfar가 작업 공간에 써 둔 에이전트가 있습니다("Molfar의 초안").

## 편집기

편집을 멈추고 잠시 후 초안으로 저장됩니다. 탭 세 개: 카드(선택한 카드), 에이전트(이름, 실행 시점, 메모리, 패널), 시험. 검사에서 "검사 통과", 문제 및 경고 수, "실행당 모델 호출 N회"가 표시됩니다. 문제가 남아 있으면 설치할 수 없습니다. "파일로 내보내기"는 공유할 수 있는 파일 하나를 저장합니다. 채팅의 "에이전트 설치 및 관리..." 시트에는 에이전트 파일을 가져오는 "에이전트 파일 설치"가 있습니다.

## 시험 실행

시험 탭은 아무것도 건드리지 않고 가상의 턴 하나를 실행합니다. 입력을 바꾸면 보드의 연결선이 어떻게 움직이는지 보여줍니다. 모델이 없으면 각 "모델에게 질문" 카드는 편집 가능한 예시 답을 사용합니다. "실제 채팅" 아래에서 채팅을 고르고 "이 채팅에서 채우기"를 누르면 에이전트가 실제로 받을 내용을 불러옵니다. 그다음 "모델로 실행"은 실제 질문으로 실제 모델에게 묻습니다. 호출 최대 N회, 실제 토큰 사용, 채팅이나 에이전트에는 아무것도 저장되지 않습니다.

## 설치, 허용, 채팅에서 켜기

1. "설치"를 누르세요(설치된 에이전트를 변경한 사본은 "업데이트"; 변경하려면 "사본 편집" 사용).
2. 한 번 허용하세요: "권한 검토" 후 "모두 허용" 또는 줄별로 허용. 모든 줄이 켜져야 실행됩니다. 더 많은 것을 요구하는 업데이트는 새 허용을 기다립니다.
3. 채팅에 추가하세요. 채팅 헤더의 알약에서 **에이전트** 탭을 여세요: "이 채팅에서"는 활성 에이전트를, "설치됨"은 나머지를 나열합니다(하나를 골라 추가). 목록에서 지금 다시 실행하거나, 제거하거나, 기다리는 답장을 멈출 수 있습니다. 새 채팅에는 에이전트를 추가하거나 세트를 고르기 전까지 에이전트가 없습니다.

**세트**는 이름 붙은 에이전트 목록입니다("이 채팅의 목록을 세트로 저장"; "기본값으로 설정"은 새 채팅에 적용). 캔버스의 "에이전트 세트" 보드는 각 세트의 시간과 호출 비용을 보여주고, 모든 에이전트의 메모를 숨기는 "채팅 속 에이전트 메모" 스위치가 있습니다. 각 에이전트의 결과 표시 위치는 채팅의 에이전트 탭에서 적합한 위치 중에 바꿀 수 있습니다.

각 "모델에게 질문" 카드는 실행당 호출 1회입니다. 편집기에 횟수가 표시됩니다. "N번째 답장마다"는 비용을 나눕니다.
