# Canvas: 채팅 링크, 프롬프트, 에이전트

Canvas는 Roleplay의 기술 작업대입니다. 보드가 있는 하나의 화면으로, 채팅들이 어떻게 연결되는지와 각 채팅이 모델에 무엇을 보내는지를 보고 바꿉니다. 플레이하는 데는 필요 없습니다. 이야기에 후속편이 필요하거나, 답장이 놀라웠거나, 에이전트를 만들 때 여세요.

맨 위의 **Board** 스위치로 보드를 고르세요: **Chat links**, **Prompt**, **Agents**, **Agent sets**. 레일의 에이전트 항목은 같은 Canvas를 에이전트 보드로 엽니다. 마지막으로 쓴 보드는 기억됩니다.

## Chat links

채팅 지도입니다. 각 채팅은 카드 하나입니다. 한 채팅에서 다른 채팅으로 이어지는 선은 "이 채팅은 저 채팅을 잇는다"는 뜻입니다. 앞 채팅의 이야기가 뒤 채팅의 답장에 배경 이야기로 따라오며, 라이브러리에서 정한 배경 이야기 예산 안에서 그렇습니다. 가장 가까운 앞 채팅 세 개는 전체가 읽히고, 더 오래된 것은 압축됩니다([[long-chats]]). 실선은 이어짐입니다. 점선은 메시지에서 갈라져 나온 분기입니다.

- 보드에 올리지 않은 채팅은 왼쪽 목록(**Chats**)에서 기다립니다. 하나를 보드로 끌어 놓거나 **Put on the board**를 쓰세요. **its linked chats**와 함께 하면 전체 체인을 가져옵니다. 카드를 목록으로 다시 끌거나 **Remove** 버튼을 쓰면 보드에서 내려갑니다. 채팅 자체는 라이브러리에 남습니다.
- **Edit** 스위치를 켜면 카드를 연결하거나 끊을 수 있습니다. 순환을 만들거나, 채팅을 자기 자신에 잇거나, 이미 있는 연결을 반복하는 링크는 거부되며, 보드가 이유를 알려줍니다. **Undo**와 **Redo**가 있습니다. **Fit**은 전체 그래프를 화면에 맞춥니다.
- 휴대폰에서는 보드가 **View**로 열리고, 링크는 **List** 보기로 보입니다. 그래프를 만드는 것은 큰 화면에서 더 쉽지만, 목록에서도 여전히 링크를 편집할 수 있습니다.

라이브러리의 채팅 지도는 같은 체인을 보여주지만 보기만 가능합니다. 그 **Edit on canvas** 버튼이 당신을 여기로 데려옵니다.

## Prompt

채팅을 골라 그 채팅이 모델에 보내는 요청을 보세요. 보드에는 두 가지 보기가 있습니다: **Parts**와 **Memory**.

- **Parts**는 요청의 모든 부분을 나열합니다: 메인 프롬프트, 캐릭터 카드, 페르소나, 로어북 항목, 예시 대화, 프리셋 섹션, 기록. 각각 토큰 수와 상태가 함께 나옵니다. 부분은 프리셋에서 꺼져 있거나, 이 채팅에서 꺼져 있거나, 비어 있거나, 이런 종류의 답장에는 해당하지 않을 수 있습니다. 프리셋을 건드리지 않고 이 채팅 하나에 대해서만 부분을 끌 수 있습니다. **Only what is sent**는 나머지를 숨기고, 합계는 모델이 받는 것을 보여줍니다.
- **Memory**는 메모리가 마지막 답장에 무엇을 넣었는지 설명합니다. 전체 설명은 [[memory]]에 있습니다.

마지막 답장에서 무엇이 발동했는지만 빠르게 보려면 채팅 헤더의 **Fired** 버튼을 쓰세요. Memory 뷰와 **Fired**는 같은 기록을 읽습니다. **Fired**는 또한 채팅 전체를 셉니다.

## Agents and Agent sets

에이전트 공방입니다: 에이전트를 만들고, 시험하고, 여러 에이전트를 세트로 묶습니다. [[agents]] 참조.

## 그대로 남는 것

Prompt 보드에서 부분을 끄는 것은 그 채팅 하나에만 적용됩니다. 프리셋과 카드는 바뀌지 않습니다.
