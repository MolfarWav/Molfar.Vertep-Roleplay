# 첫 번째 이야기

빈 Roleplay에서 진행 중인 이야기까지 가는 가장 짧은 길과, 놀라지 않도록 저절로 일어나는 일의 목록입니다. 먼저 모델 연결이 필요합니다: [[vertep:models]] 참조.

## 단계

1. **카드를 얻으세요.** 홈에서 "New character"를 눌러 직접 쓰거나, "Import card"로 파일에서 PNG나 JSON 카드를 가져오세요. 마켓플레이스 구역에서 검색할 수도 있고, "With Molfar"를 눌러 아이디어를 바탕으로 Molfar가 카드 초안을 쓰게 할 수도 있습니다. [[characters]] 참조.
2. **저장하세요.** 카드 편집기는 "Save changes"를 누를 때까지 편집 내용을 초안으로 보관합니다.
3. **페르소나를 고르세요**(당신이 연기할 인물). 페르소나 구역에서 고르거나 기본값을 그대로 두세요. "Use this persona"는 그것을 기본값으로 만듭니다.
4. **채팅을 시작하세요.** 카드에서 "New chat"을 누르세요. 채팅이 카드의 첫 메시지와 함께 열립니다.
5. **모델을 확인하세요.** 채팅 헤더의 알약 모양 버튼에 Model 탭이 있습니다. 거기서 모델을 고르면 이 채팅만 바뀝니다.
6. **쓰세요.** 각 답장 아래에서 다른 버전(스와이프)을 넘겨 볼 수 있습니다. 마지막 버전의 오른쪽 화살표는 새 버전을 요청합니다. 방향을 정해 답장을 다시 하려면 "+" 메뉴의 "Regenerate with a hint"를 쓰세요. 메시지의 "More" 버튼에는 편집, 분기, 프롬프트 보기 등이 있습니다.

## 저절로 실행되는 것

채팅에 답장이 생기면 백그라운드 도우미들이 작동하며, 각자 모델 호출을 합니다:

- Dashboard가 답장마다 장면을 읽습니다([[dashboard]]).
- Litopys가 장면이 닫힐 때 챕터를 씁니다([[litopys]]).
- World DM이 가장 낮은 활성 단계(기록자)에서 이 채팅의 책에 사람과 장소를 기록합니다([[world-dm]]).
- 소울이 없는 카드에는 자동으로 하나가 제안됩니다([[soul]]).

이 작업들의 실패는 Inbox에 나열됩니다.

## 모델이 작거나 느리거나 호출마다 요금이 붙는다면

가장 저렴하게 아끼는 방법, 순서대로:

1. Dashboard의 "Settings"에서 모드를 "Manual"로 설정하세요(그러면 새로고침을 누를 때만 갱신됩니다). 또는 "Sensor model"로 작은 모델을 고르세요.
2. Library의 "Litopys settings"에서 "Memory size"를 낮추거나 "Chapters and facts"를 끄세요.
3. World 시트에서 "Off" 단계를 고르세요(장면이 새 장소를 이름 붙이면 여전히 작은 호출을 하나 합니다). 또는 저렴한 "DM model (all chats)"를 고르세요.
4. Dashboard 설정에서 "Rate characters automatically"를 끄세요.
5. Canvas의 Prompt 보드는 다음 요청의 모든 부분을 토큰과 함께 보여 주고, 채팅 하나에 대해 부분을 끌 수 있게 합니다.

길어진 이야기에는 따로 조치가 필요합니다: [[long-chats]] 참조.

작은 컨텍스트 창을 가진 무료 모델은 수동 대시보드와 Compact 메모리에서 가장 잘 작동합니다.
