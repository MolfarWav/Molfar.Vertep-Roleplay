# Où sont les réglages de Roleplay

Roleplay n'a pas une seule page de réglages pour tout. Les réglages se trouvent près de ce qu'ils changent, et deux d'entre eux sont dans les Réglages principaux de Molfar Vertep. Cette page est un index.

## Deux Réglages, à ne pas confondre

- **The main Settings** de Molfar Vertep (l'engrenage de toute la page) : modèles et connexions, sauvegardes de tout le profil, mises à jour. Choisissez et testez les modèles là-bas ; voir [[vertep:settings]] et [[vertep:models]]. Les modèles étoilés y apparaissent comme changements rapides dans une discussion.
- **Roleplay settings** : le bouton « Roleplay settings » dans l'en-tête de Home (sur un téléphone, dans le menu). Les Réglages principaux listent aussi cette application : sous « Réglages des apps », en haut, appuyez sur l'application (son nom y est « Vertep ») et elle s'ouvre sur cette page. Il a dix sections : Appearance, Chat Behavior, Streaming, Themes, Prose Colors, Custom CSS, Card tasks, Import, Data et Guide. Une zone de recherche en haut les filtre.

Ce que font les sections, en bref : Appearance règle la langue, les polices, la largeur de discussion et les avatars ; Chat Behavior a des interrupteurs comme envoyer avec Entrée, confirmer les suppressions, et « Spell check in the message box » et « Autocorrect in the message box » (tous deux désactivés par défaut : le correcteur orthographique souligne les mots mal orthographiés et propose des corrections, ce qui, pour des noms inventés, fait beaucoup de rouge ; la correction automatique laisse le clavier modifier les mots, ce qui sur un téléphone peut se heurter aux astérisques, aux guillemets et aux macros ; ils s'appliquent à la zone de message et à l'éditeur agrandi) ; Streaming choisit de montrer les réponses au fur et à mesure ou à la fin ; Card tasks choisit le modèle utilisé par les assistants de carte (« Structure it », « Fill empty ») quand une carte n'a pas les siens ; Import fait entrer des préréglages, personnages, livres de connaissances, discussions et un zip de sauvegarde (un préréglage SillyTavern arrive avec ses listes de choix sous forme de Choix, les explications de l'auteur sous forme de notes et ses blocs « do not touch » verrouillés ; un préréglage exporté depuis Roleplay revient avec tous ses Choix) ; Data exporte et restaure les données propres de Roleplay en zip (tout le profil est sauvegardé par la Sauvegarde des Réglages principaux) ; Guide montre ou masque les courtes visites et « What's new ».

## Réglages qui vivent ailleurs dans Roleplay

- **Dashboard** : son bouton « Settings », avec les onglets Sensor, Event vocabulary, « What the model sees » et « Tune with Molfar ». Voir [[dashboard]].
- **Litopys** : l'engrenage « Litopys settings » dans la Library. Voir [[litopys]].
- **World DM** : la feuille Monde dans l'en-tête de la discussion et la section Monde ; « World settings » contient le modèle DM. Voir [[world-dm]].
- **Agents** : les tableaux Agents et « Agent sets » du Canvas et l'onglet Agents de la discussion. Voir [[agents]].
- **Requête et échantillonnage** : la section **Presets** (sections que vous pouvez changer, variables, échantillonneurs, et un aperçu de la requête finale) et le tableau Prompt du Canvas pour une discussion. Le panneau Preset d'une discussion affiche, sous le nom du préréglage, une ligne « Works with » : les fonctions de cette discussion pour lesquelles le préréglage a des règles (Dashboard, Litopys, World DM, dés...), et lesquelles sont désactivées dans cette discussion.
- **Ce qui est propre à une carte** : ses onglets d'éditeur, y compris couleurs, regex et options avancées. Voir [[characters]].
- **Livres de connaissances** : chaque livre a ses propres règles (profondeur d'analyse, plafond de taille, interrupteur Global). Voir [[memory]].
- **La Inbox** a des interrupteurs par sorte pour ce qui compte comme en attente de vous.

## Tools

La section **Tools** est une rangée d'onglets, groupés en Panels (panneaux de plugins comme Tool Calling), Text & voice et System.

- **Regex** : scripts de recherche-remplacement qui ne fonctionnent que dans les endroits que vous activez.
- **Translation** : fournisseur, deux langues et un mode de traduction automatique ; traduit aussi la discussion ouverte.
- **Image Generation** : le modèle de discussion décrit la scène et un modèle d'image la dessine. Désactivé par défaut. Avec le mode interactif activé, vous vérifiez d'abord chaque requête.
- **TTS** : lit les réponses à voix haute. Désactivé par défaut.
- **Data Bank** : documents texte utilisés pour la récupération ([[memory]]).
- **Backgrounds** : les images derrière vos discussions.
- **MCP** : serveurs d'outils partagés par le moteur. Chacun commence désactivé dans cette application ; activez ce dont vous avez besoin.
- **Plugins** : montre quels plugins tournent derrière l'application et ce que chacun peut faire. L'installation, l'activation et la désactivation se font avec le bouton Plugins dans Molfar Vertep, pas ici.
- **Tool Calling** (dans Panels) : permet au modèle d'utiliser des outils pendant l'écriture. Dice Roller et Picture sont intégrés et restent désactivés jusqu'à ce que vous les activiez.

Aussi : **Shortcuts** contient les réponses rapides, qui peuvent s'exécuter seules sur des événements ; Themes change la palette immédiatement, Prose Colors recolore la parole et la narration, et Custom CSS est appliqué en dernier. Une discussion peut aussi avoir son propre CSS : dans la discussion, **More** > **Chat CSS**. Il s'affiche pendant que vous tapez, ne s'applique qu'à cette discussion et l'emporte sur le Custom CSS global et sur le CSS de la carte.
